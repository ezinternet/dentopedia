## Three-line Summary

International Delphi consensus study (Manchester/FDI/Melbourne/Lorraine; J Dent 2023) developing the first core outcome set (COS) for dental antibiotic stewardship interventions, with multistakeholder input from ≥30 clinicians, academics, and patients.

Consensus-defined core outcome set established using >70% "critical for inclusion" threshold, enabling standardized outcome reporting across future stewardship intervention trials.

First international COS for dental antibiotic stewardship; key limitation is that it defines outcomes for research, not direct prescribing data, and local adaptation will be required for non-English-speaking contexts.

## 세줄요약

국제 Delphi 합의 연구(Manchester/FDI/Melbourne/Lorraine; J Dent 2023): 치과 항생제 스튜어드십 개입 연구를 위한 최초 핵심 아웃컴 세트(Core Outcome Set, COS) 개발; ≥30명 임상가·학자·환자 다이해관계자 참여.

'포함에 필수(critical)' 기준 >70% 임계값으로 합의된 핵심 아웃컴 정의; 향후 스튜어드십 임상시험 결과 보고 표준화 목적.

치과 항생제 스튜어드십 최초 국제 COS; 핵심 한계는 연구 아웃컴 정의에 초점 맞추어 직접 처방 데이터 없으며 비영어권 맥락 현지 적용 필요.

## Summary
International Delphi consensus developing a core outcome set (COS) for dental antibiotic stewardship intervention research. Patient, academic, and clinician representation. Establishes which outcomes future stewardship trials should report as standard, enabling comparison and meta-analysis across interventions.

## Key Contributions
- First international COS for dental antibiotic stewardship.
- Multistakeholder (patient + clinician + academic) input.
- Standardizes outcome reporting in future stewardship trials.

## Methodology
Delphi consensus; outcomes sourced via literature review; ≥30 international participants; ≥70% "critical for inclusion" threshold for COS inclusion.

## Results
[확인] Core outcome set defined; specific items in paper.

## Limitations
- Process-focused, not direct prescribing data
- Local adaptation required for non-English-speaking contexts
