## Three-line Summary

Systematic review and network meta-analysis (Semmelweis group; PRISMA-NMA; Bayesian/frequentist framework with SUCRA ranking) comparing all placement timing (types 1–4) × loading protocol (immediate/early/conventional) combinations for single anterior maxillary implants on survival, MBL, PES, and patient satisfaction.

Type 1A (immediate placement + immediate loading) and Type 1B (immediate placement + delayed loading) achieved equivalent outcomes to conventional protocols under appropriate case selection, but Type 1A showed higher operator and case-selection dependency.

For anterior maxillary single implants, Type 2/3 + conventional or early loading is the safest general recommendation; Type 1A applies when the Hamilton 2023 ITI selection criteria are fully met.

## 세줄요약

SR+NMA (Semmelweis 그룹; PRISMA-NMA; Bayesian/frequentist 프레임워크, SUCRA 순위): 상악 전치부 단일 임플란트에서 식립 시기(Type 1–4) × 부하 시기(즉시/조기/통상) 조합 전체를 생존율·MBL·PES·PROMs로 비교.

Type 1A(즉시식립+즉시부하)와 Type 1B(즉시식립+지연부하) 모두 적절한 증례 선택 하에 통상 프로토콜과 동등한 결과; 단, Type 1A는 술자 및 증례 의존도가 높음.

상악 전치부 단일치에서 Type 2/3 + 통상/조기 부하가 가장 안전한 일반 권고; Type 1A는 Hamilton 2023 ITI 선택 기준을 완전히 충족하는 경우에만 적용한다.
