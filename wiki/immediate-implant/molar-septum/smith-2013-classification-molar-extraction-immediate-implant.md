## Three-line Summary

Landmark technical note (Columbia University, IJOMI 28(3):911-916, 2013) that introduced the **A/B/C classification** of molar extraction sockets for immediate implant placement, stratifying sockets by the amount of inter-radicular septal (IRS) bone available for primary stability: **Type A** (implant fully within septal bone, no gaps), **Type B** (partial septal engagement, gaps on ≥1 surface), **Type C** (minimal/absent septum, implant must engage socket periphery).

Each type carries a distinct treatment protocol and risk profile: Type A is predictably favorable; Type B requires gap management; Type C is high-risk and typically warrants delayed placement or prior augmentation.

This classification became the standard taxonomic framework for the molar immediate implant literature, operationalized with CBCT measurements by Milenkovic 2022, Pavlovic 2022, Deporter 2021, and validated against survival data by Ragucci 2020 SR+MA.

## 세줄요약

랜드마크 기술보고 (컬럼비아 의대, IJOMI 2013) — 구치 발치와를 격중격 (Interradicular Septum, IRS) 내 잔존골량에 따라 **A/B/C 3단계**로 분류: **Type A**(격중격이 임플란트를 완전히 감쌈, 틈 없음), **Type B**(격중격 부분 고정, 일부 면에 틈), **Type C**(격중격 거의 없음, 발치와 주변골에 걸쳐야 함).

치료 프로토콜: Type A = 즉시식립 예측 가능 / Type B = 즉시식립 가능, 틈 관리 필수 / Type C = 고위험군, 지연식립 또는 골증대 권고.

이후 Milenkovic 2022·Pavlovic 2022·Deporter 2021이 CBCT 계측치로 정량화, Ragucci 2020 SR+MA가 생존율로 검증 — 구치 즉시식립 문헌의 표준 분류 기준.

## The A/B/C Classification

Classification criterion: bone available within the extraction socket for stabilization of an immediately placed implant.

| Type | Septal Bone | Implant-Socket Relationship | Gaps | Primary Stability Source |
|---|---|---|---|---|
| **A** | Adequate — fully engages implant | Implant completely within septal bone | None | Septum alone |
| **B** | Adequate for stabilization, not containment | Partial septal engagement | ≥1 surface gap | Septum + socket walls |
| **C** | Little to none | Implant engages socket periphery | Large/circumferential | Socket walls / apical bone |

## Clinical Decision Framework

```
Pre-surgical CBCT → assess IRS (height, width, density)
         │
    Type A?  ───→  Predictable IIP; implant within septum
         │
    Type B?  ───→  IIP possible; plan gap graft + membrane
         │
    Type C?  ───→  High-risk: delayed placement OR
                   socket augmentation → re-entry OR
                   septal expansion (OD technique — Bleyan 2021)
```

**Key intraoperative check**: after extraction, probe the septal bone height and width; confirm the planned implant can achieve ≥3–4 mm primary stability in the septum before committing to Type A/B protocol.

## Limitations

- No outcome data — survival rates by socket type not reported
- No CBCT measurement thresholds — quantification added by later studies
- Does not address socket infection, periapical pathology, or systemic modifiers
- Molar-specific: not intended for single-rooted sockets
