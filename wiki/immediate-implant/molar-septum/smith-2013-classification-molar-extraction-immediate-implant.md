## Three-line Summary

Landmark technical note (Smith & Tarnow) introducing the A/B/C classification of molar extraction sockets for immediate implant placement based on inter-radicular bone available for primary stability: Type A (septum fully engages implant), Type B (partial engagement), Type C (insufficient bone for predictable stability).

The classification provides a treatment-decision framework for molar IIP feasibility; subsequent CBCT-based studies (Pavlovic 2022, Milenkovic 2022, Deporter 2021, Ragucci 2020 SR+MA) operationalize and validate the original criteria.

Type A/B assessment should be performed with pre-surgical CBCT; Type C sockets require delayed placement or augmentation rather than immediate implant — this conceptual framework remains the standard for molar IIP literature.

## 세줄요약

랜드마크 technical note (Smith & Tarnow): 구치 발치와를 격중격(IRS) 활용 가능성에 따라 Type A(완전 고정), Type B(부분 의존), Type C(고정 불충분)의 3단계로 분류 — 1차 안정성 기반 즉시식립 의사결정 프레임워크.

이 분류 체계는 이후 CBCT 기반 연구들 (Pavlovic 2022, Milenkovic 2022, Deporter 2021, Ragucci 2020 SR+MA)에 의해 정량화·검증.

수술 전 CBCT로 Type A/B를 평가해야 하며, Type C 발치와는 즉시식립 대신 지연식립 또는 골증대가 필요 — 이 분류는 구치 즉시식립 문헌의 표준 참조 체계로 남아 있다.

## Summary
Technical note introducing the A/B/C classification of molar extraction sockets for immediate implant placement based on the inter-radicular bone available for primary stability.

## Key Contributions
Foundational classification system used in virtually all subsequent molar-IIP literature. Anchors the decision of whether a molar socket is amenable to immediate implant.

## Methodology
Conceptual classification + clinical illustration. Type A: implant fully engages inter-radicular bone; Type B: partial engagement requiring stability from socket walls/apical bone; Type C: insufficient bone for predictable stability.

## Results
Provides a treatment-decision framework that subsequent studies (Pavlovic 2022, Milenkovic 2022, Deporter 2021, Ragucci 2020) operationalize via CBCT measurements.

## Limitations
Not an outcome study; classification not validated against survival data within this paper.
