## Three-line Summary

Systematic review (69 publications: 23 comparative [15 RCTs, 7 CCTs], 47 noncomparative [34 prospective, 13 retrospective]; 5,248 titles → 449 full texts screened) of implant placement × loading protocol combinations (9 type combinations) in partially edentulous patients with solid-screw rough-surface implants (3–6 mm diameter).

Weighted cumulative survival rates by type: Type 1A 98.4%, Type 1B 98.2%, Type 1C 96.0%; Type 2–3B 100%, Type 2–3C 96.3%; Type 4A 97.9%, Type 4B 98.3%, Type 4C 97.7%. Evidence classification: Type 1C, Type 2–3C, Type 4B, Type 4C scientifically and clinically validated (SCV); Type 1A/1B/4A clinically documented (CD); Type 2–3A/2–3B clinically insufficiently documented (CID).

Loading protocol selection significantly influences the outcome of immediate implant placement; evidence heterogeneity is high, precluding meta-analysis. Primary clinical message: placement and loading decisions must be made in **combination**, not analyzed separately.

## 세줄요약

부분무치악 환자에서 임플란트 식립 시점(Type 1–4: 즉시/조기/지연) × 부하 프로토콜(즉시/조기/종래식) 조합의 임상 결과를 검토한 체계적 문헌고찰(Systematic Review, SR). 69개 발행물(비교연구 23편 [무작위대조시험(Randomized Controlled Trial, RCT) 15편, 대조임상시험(Controlled Clinical Trial, CCT) 7편], 비교 외 연구 47편; 제목 5,248건 검색 → 전문 449편 평가).

가중 누적 생존율(Weighted Cumulative Survival Rate)은 Type 1A 98.4%, 1B 98.2%, 1C 96.0%; Type 2–3B 100%, 2–3C 96.3%; Type 4A 97.9%, 4B 98.3%, 4C 97.7%; 근거 분류상 Type 1C·2–3C·4B·4C는 과학적·임상적으로 검증됨(Scientifically and Clinically Validated, SCV), Type 1A/1B/4A는 임상적으로 문서화됨(Clinically Documented, CD), Type 2–3A/2–3B는 임상적 근거 불충분(Clinically Insufficiently Documented, CID)으로 분류.

핵심 임상적 함의 — 식립 시점과 부하 프로토콜은 따로가 아니라 **조합**으로 선택·분석해야 하며, 즉시 식립의 결과는 부하 프로토콜 선택에 크게 좌우됨; 이질성이 높아 메타분석(Meta-Analysis, MA)은 시행하지 못함.

## Summary

This ITI Consensus-aligned systematic review synthesizes 69 publications (5,248 titles screened, 449 full texts assessed) to quantify weighted cumulative implant survival across all nine combinations of placement timing (Type 1 immediate, Types 2–3 early, Type 4 late) and loading protocol (immediate, early, conventional) in partially edentulous patients restored with solid-screw, rough-surface implants (3–6 mm diameter). Weighted survival ranged from 96.0% to 100% across the nine protocols, but high study heterogeneity precluded formal meta-analysis, so the authors instead applied a three-tier evidence-validation framework — scientifically and clinically validated (SCV), clinically documented (CD), and clinically insufficiently documented (CID) — that grades confidence in each combination independently of its raw survival number. Type 1A and Type 1B (immediate placement with immediate or early loading) achieved high survival (98.4%, 98.2%) but were graded only CD because their supporting evidence was less standardized than for conventional-loading protocols, while Type 2–3B (early placement + early loading) reached 100% survival on a sparse evidence base (CID). The central clinical message is that placement timing and loading protocol cannot be evaluated independently of each other — the loading protocol chosen significantly modifies the outcome of immediate implant placement — so treatment planning must select the pair as a single combined decision rather than two separate ones.

## Key Contributions

- Systematic quantification of **weighted cumulative survival rates** for all 9 placement × loading type combinations in partially edentulous patients (5,248-title search, 69 publications).
- Introduces a **three-tier evidence-validation framework** (SCV / CD / CID) that grades confidence in a given protocol combination separately from its raw survival percentage — a framework later carried forward largely unchanged into [[implants/gallucci-2026-current-state-of-evidence-for]]'s 4-tier update.
- Demonstrates that **loading protocol selection significantly modifies the outcome** of immediate (Type 1) implant placement — the two variables cannot be planned independently.
- Establishes the operational ITI **Type 1–4 placement / A–B–C loading nomenclature** (immediate <1 week / early 1 week–2 months / conventional >2 months) used by essentially all subsequent placement-timing literature in this wiki.
- Notes that post-extraction alveolar ridge dimensional changes are **not mitigated by immediate placement alone** — labial/buccal bone thickness and GBR still govern long-term esthetic outcome.

## Methodology

Systematic review with cumulative (not meta-) analysis of Medline, Embase, and Cochrane Central. Inclusion: human studies, ≥10 cases, ≥12-month follow-up, solid-screw rough-surface implants with 3–6 mm intra-osseous diameter. Screening funnel: 5,248 titles → 2,362 abstracts → 449 full-text articles → 69 included publications (23 comparative: 15 RCTs + 7 CCTs; 47 noncomparative: 34 prospective + 13 retrospective cohorts). Primary outcome: cumulative survival rate (implant- and patient-level), weighted by follow-up duration and implant number, computed separately for each of the 9 placement × loading combinations rather than pooled.

## Results

| Protocol | Definition | Weighted survival | Validation |
|---|---|---|---|
| Type 1A | Immediate placement + immediate loading | 98.4% | CD |
| Type 1B | Immediate placement + early loading | 98.2% | CD |
| Type 1C | Immediate placement + conventional loading | 96.0% | SCV |
| Type 2–3A | Early placement + immediate loading | data insufficient | CID |
| Type 2–3B | Early placement + early loading | 100% | CID |
| Type 2–3C | Early placement + conventional loading | 96.3% | SCV |
| Type 4A | Late placement (≥6 mo) + immediate loading | 97.9% | CD |
| Type 4B | Late placement + early loading | 98.3% | SCV |
| Type 4C | Late placement + conventional loading | 97.7% | SCV |

Study composition: 23 comparative studies (15 RCTs, 7 CCTs) + 47 noncomparative studies (34 prospective, 13 retrospective cohorts); heterogeneity across study design, implant type, follow-up duration, and outcome definition was high enough that no meta-analysis of the controlled studies was possible. Type 1A/1B (high survival but CD) and Type 2–3B (100% survival but CID) are the clearest illustration of the paper's own point: raw survival percentage and evidence-validation tier do not move together.
