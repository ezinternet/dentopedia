## Three-line Summary

Narrative review (Yonsei University and Gangnam Severance Hospital, JKDA 62(1) 2024) examining the diagnostic tools available for cracked tooth syndrome and their individual limitations — the first article of the JKDA cracked tooth special series.

Each single tool has characteristic failure modes: transillumination misses deep cracks, bite test yields false positives/negatives, dye staining is invasive, and CBCT cannot directly visualize cracks; the paper proposes a sequential 5-step multi-test framework from history through endo-entry confirmation.

No primary data — consensus-level narrative review; single-tool dependence risks overdiagnosis or missed diagnosis, and a comprehensive multi-tool framework is the clinically appropriate response.

## 세줄요약

연세대·강남세브란스 보존과 대한치과의사협회지 62(1) 2024 서술적 리뷰 — 균열치 진단 도구별 한계를 검토하고 다중 검사 종합 framework를 제안한 JKDA 균열치 특집 1편.

투조: 깊은 균열 누락; bite test: 위양성·위음성; 색소 도포: 침습적; CBCT: 균열 직접 시각화 어려움; 5단계 순차 framework(병력→시각+투조→bite test→CBCT→endo 진입 최종 확인)로 단일 도구 한계 극복.

1차 데이터 없는 합의수준 서술 리뷰 — 단일 도구 의존은 과잉·과소 진단 위험이 있으며 종합 다중 도구 접근이 임상적 표준이다.

## Diagnostic Tools

| 도구 | 장점 | 한계 |
|---|---|---|
| Visual + transillumination | 빠름, 비침습 | 깊은 crack 누락 |
| Dye staining (methylene blue) | 시각화 | 시술 침습 |
| Bite test (Tooth Slooth) | 환자 호소 재현 | 위양성·위음성 |
| CBCT | 3D | Crack은 직접 시각화 어려움 |
| 진단 결정 검사 | endo 진입 후 직접 확인 | 비가역적 |

## Clinical Framework
1. Patient history (sharp pain on chewing release)
2. Visual + transillumination
3. Bite test (cusp별 sequential)
4. CBCT (deep crack·root involvement 의심)
5. Tentative diagnosis → endo 진입 후 final confirmation
