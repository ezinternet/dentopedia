## 한국어 핵심요약

> [!summary] 한국어 핵심요약
> - 핵심 결론: 근관치료 정립 프로토콜은 **5단계** — ①접근와동(Access Cavity) → ②근관형성(Shaping) → ③작업장 측정(Working Length) → ④세정·소독(Irrigation & Activation) → ⑤근관충전(Obturation) — 이 수렴한다. 최종 보철(Coronal Restoration) 밀폐가 최대 예후 인자.
> - **TEC(전통직선접근)가 표준**. MIA(최소침습)는 임상 RCT 없이 잔류 debris↑·근관구 탐지↓·천공 위험↑ — 숙련 술자의 단순 단근관에서만 선택적. 복잡 해부는 유도 근관치료 고려.
> - **세정이 핵심 병목** — 기구는 근관벽 10–80%를 못 건드리고, 형성 후에도 30–60%가 세균 양성. PUI(수동초음파세정)가 임상 근거 1순위(Orozco-Gallego 2025: 미생물 RD −0.15, 치유 RD −0.09). CNI(일반 주사기) 단독은 절대 금지.
> - **작업장(WL)은 고정값이 아니라 진단 종속** — 생활치수·무병소는 근첨에서 약간 물러남(RA−1mm), 괴사+근단치주염은 AC 근접(RA−0.5mm). EAL "0"에서 전치 −0.85mm·구치 −0.70mm 권장 (기존 −0.5mm는 AC 미도달).
> - **근관충전은 AC(방사선 근첨에서 0–2mm short)까지 dense fill, extrusion 없음**. 충전 기법(SC·CLC·WVC·CB)은 3년 이후 장기 결과에서 차이 소멸 — 술자 숙련도와 해부에 선택.
> - **최종 보철 적합도가 최대 예후 인자** (Llena 2020) — 세정·충전 품질만큼 중요. coronal leakage가 치유 실패 주원인.
> - 모든 세정제가 상아질을 연화·화학변성시킴 → 농도·시간 절제, 액상 선호. NaOCl+EDTA 사이 반드시 증류수 중간세정 (PCA 침전 방지).

## Three-line Summary

Synthesis of 50+ endodontics papers (SR+MA, umbrella reviews, RCTs, landmark cohort studies) into the established 5-stage root canal treatment protocol from access cavity to obturation, drawing on overviews in access-cavity, EAL working-length, irrigation activation, and obturation length.

Stage 1 (Access): TEC standard for normal anatomy; MIA is conditionally attractive but evidence-deficient; guided endodontics for PCO/complex anatomy. Stage 2 (Shaping): conservative NiTi instrumentation as irrigation access, not cleaning — instruments leave 10–80% of canal walls untouched (Siqueira 2018). Stage 3 (WL): EAL "0" minus 0.85 mm (anterior) / 0.70 mm (posterior); diagnosis-dependent tuning — vital cases tolerate a shorter terminus, necrosis + AP requires close-to-apex debridement (Chugal 2003: +14% failure per mm of WL loss). Stage 4 (Irrigation): NaOCl + PUI first-line, EDTA second-line, distilled-water intermediate flush mandatory, CNI single-use prohibited (Orozco-Gallego 2025 umbrella). Stage 5 (Obturation): fill to AC (0–2 mm short of radiographic apex), dense void-free, no extrusion; technique equivalence beyond 3 years (Mushtaq 2026 SR+MA 84 studies, n=11,965). Final coronal restoration quality is the dominant prognostic factor (Llena 2020).

## 세줄요약

근관치료 정립 프로토콜 5단계: ①TEC 직선접근(표준) → ②보존적 NiTi 형성(세정 접근로 확보, 기구는 벽의 10–80% 미준비) → ③EAL 기반 작업장 측정(진단 종속: 전치 −0.85mm·구치 −0.70mm; 괴사+AP는 근첨 근접) → ④NaOCl+PUI+EDTA 세정(활성화 필수, CNI 단독 금지) → ⑤AC까지 dense 충전(extrusion 없음, 기법은 장기 동등).

최종 보철 밀폐가 최대 예후 인자(Llena 2020); 충전 기법은 3년 이후 차이 소멸(Mushtaq 2026); 단회치료로 충분(단회 ≥ 다회; Wong 2015 RCT, Rossi-Fedele 2023 SR+MA).

## Thesis

This overview answers the question: **what is the evidence-based step-by-step protocol for root canal treatment from initial access through final obturation?** The answer synthesizes 50+ papers across 4 sub-categories (access-cavity, shaping, EAL/working-length, irrigation, obturation) and landmark outcome studies, converging on a 5-stage pipeline where the key insight is that each stage has a distinct dominant rationale: access → straight-line instrument passage; shaping → irrigation access (not cleaning); working length → diagnosis-dependent apical terminus; irrigation → chemical disinfection of unprepared surfaces; obturation → hermetic seal to the apical constriction. The overarching finding is that **preoperative pulpal/periapical status is the dominant prognostic factor**, while the operator-controllable levers (WL accuracy, irrigation activation, coronal seal) are layered on top. Filling technique is a secondary variable that converges to equivalence beyond 3 years.

## Stage 1 — 접근와동 (Access Cavity)

### 핵심 원칙: 직선 진입 (Straight-Line Access)

```
  직선 진입 O                  직선 진입 X
  ──────────────               ───────────────
  • 회전 NiTi 기구 원활         • 굴곡 → 피로 파절
  • 세정액 침투 균등            • 세정 불균등
  • 근관 형성 예측 가능         • 치근 이상 만곡 위험
```

- **TEC(전통직선접근)**: 치수강 지붕 완전 제거 + 경부 상아질 돌출 제거 → 직선 진입. 정상 해부에서 **확립된 표준**.
- **MIA(최소침습)**: 변연능선(marginal ridge) 2개 온전 시 **조건부** 파절저항 이득 (Ballester 2021, MA 33편, 전부 in vitro); 1개라도 소실 시 이득 소멸. 임상 RCT **없음**, 잔류 debris↑·근관구 탐지↓·천공↑ → 숙련 술자의 단순 단근관에서만.
- **유도 근관치료**: PCO(석회화)·근관구 비가시·MB2·변이 해부에. 정적(SN, CBCT→3D 프린팅) vs 동적(DN, 실시간 추적).

| 케이스 | 권고 | 근거 수준 |
|---|---|---|
| 정상 해부, 단근관 | TEC | 확립 |
| 정상 해부, 다근관 | TEC + DOM + 초음파 MB2 탐지 | 확립 |
| PCO·석회화 | 유도 근관치료 (SN 또는 DN) | 전도유망 |
| 단순+숙련+변연능선 2개 온전 | MIA 선택 가능 | 조건부 (in vitro) |

> 출처: [[overviews/endodontic-access-cavity-decision-tree]], Kapetanaki 2021, Dioguardi 2024, Ballester 2021, Ribeiro 2022

## Stage 2 — 근관형성 (Shaping)

### 형성은 세정 접근로 확보, 세정 자체가 아님

| 항목 | 핵심 수치 | 출처 |
|---|---|---|
| 기구 미준비 근관벽 | 원형/소형 근관 10–50%, 타원/편평 근관 **10–80%** (근단부 심함) | [[endodontics/shaping/siqueira-2018-unprepared-root-canal-surface-areas]] |
| 형성 후 세균 양성률 | **30–60%** | Siqueira 2018 |
| 2.5% NaOCl 단독 미생물 감소 | 10²–10⁵배 (~95–99%)에 그침 | Siqueira 2018 |

- **Rotary/Reciprocating NiTi** + glide path 준비 → 근관 운반·파절 방지
- **보존적 형성(minimal instrumentation)**: 상아질 벽 두께 보존이 수직치근파절 예방과 직결 (Lee 2026)
- 형성의 목적은 **기구·세정액이 근첨까지 도달할 수 있는 통로 확보** — recess·isthmus의 biofilm 소독은 세정액의 화학작용과 활성화가 전담

> 출처: [[endodontics/shaping/siqueira-2018-unprepared-root-canal-surface-areas]], [[endodontics/shaping/lee-2026-residual-pericervical-apical-dentine-vertical]]

## Stage 3 — 작업장 측정 (Working Length / EAL)

### 핵심: WL은 고정값이 아니라 진단 종속 변수

#### 3-1. 해부학적 기준

```
crown ←────────────────────────────────→ apical tip
         ...canal...  [AC]──────[AF]  [AA]
                       ↑         ↑      ↑
               apical constriction  EAL "0"  root tip
               (이상적 충전 종지점)  (major foramen)
               = CDJ 근방
```

| 구조 | 설명 | 임상 의미 |
|---|---|---|
| **AC** (apical constriction) | 근관 최협부 | 이상적 충전 종지점, CDJ 근방 |
| **AF** (apical foramen) | 최대경 개구부 | EAL "0"이 탐지하는 지점 |
| **AA** (anatomical apex) | 치근 끝단 | 방사선 apex와 불일치 가능 |

#### 3-2. WL 설정 — 진단별 조절

| 술전 진단 | 목표 WL | 근거 |
|---|---|---|
| 생활치수 / 근단 병소 없음 | AC에서 다소 물러남 (RA −1mm 부근), 과기구조작 회피 | Chugal 2003 (성공례 WL 1.23±0.13mm); Schaeffer 2005 |
| 괴사 + apical periodontitis | AC까지 근접 (RA −0.5mm 부근), WL 손실 회피 | Chugal 2003 (1mm 손실당 실패 **+14%**); Ricucci 2011 |
| 모든 경우 공통 | dense fill · void 없음 · **extrusion 없음** | Ng 2007; Ricucci 2011; Schaeffer 2005 |

#### 3-3. EAL 설정값

| 치종 | AC–AF 거리 | 권장 WL | 기존 −0.5mm 대비 |
|---|---|---|---|
| **전치** | 0.847 ± 0.33 mm | EAL "0" **−0.85mm** | 0.35mm 더 빼야 AC 도달 |
| **구치** | 0.709 ± 0.27 mm | EAL "0" **−0.70mm** | 0.21mm 더 빼야 AC 도달 |

- EAL 3~6세대 정확도 차이 없음 (Pisano 2024) — 업그레이드는 인체공학용
- NaOCl 관개 시 측정값 단축 → flooding 전 측정 또는 후 재측정
- 한국 현황: EAL 선호 89%, "APEX −0.5mm" 읽기 41% (1위), EAL과 방사선 충돌 시 EAL 우선 74% (Ahn 2016)

> 출처: [[overviews/eal-working-length-protocol]], [[overviews/obturation-length-outcome-overview]], Mousavi 2018, Versiani 2022, Pisano 2024, Chugal 2003

## Stage 4 — 세정·소독 (Irrigation & Activation)

### 핵심 병목: 기구가 못 건드리는 벽의 biofilm은 세정액이 전담

#### 4-1. 세정 활성화 — 기법 순위

| 순위 | 기법 | 핵심 근거 |
|---|---|---|
| **1순위** | PUI (수동초음파세정) | 미생물 RD −0.15, 치유 RD −0.09 (Orozco-Gallego 2025 umbrella) |
| **1순위 동등** | ANP (EndoVac) | 근첨 도달 최선 (Kumar 2023 SR+MA) |
| **2순위** | Sonic (EndoActivator) | 근첨 1/3 도말층 제거 보강 (Paixao 2022) |
| **유망** | Er:YAG 레이저 | 대리지표 일관 우위·NaOCl 농도↓·술후 불편↓, 단 outcome RCT 부재 (Fiegler-Rudol 2025) |
| **PUI 동등·고비용** | 멀티소닉 (GentleWave) | 일관된 우위 없음, 내독소(LPS/LTA) 감소만 유의 (Varadan 2025, Usta 2026) |
| **비권장** | CNI 단독 | 모든 단계에서 절대 금지 |

#### 4-2. 세정액 — 화학 분업

| 세정액 | 역할 | 비고 |
|---|---|---|
| **NaOCl 1–6%** | 유기질 용해 + 항균 | 농도 간 임상 차이 없음 (Rossi-Fedele 2023); 단독 사용 시 무기질 제거 불가 |
| **EDTA 17%** | 도말층·무기질 제거 (표준) | 성장인자 방출 최우수 (Fortea 2024) |
| **HEDP 9–18%** | NaOCl과 양립 킬레이트제 | smear 형성 자체 예방 |
| **7% 말레산** | 근첨 도말층 제거 우위 | 1–3분 한정 (침식 제한; Rao 2025) |
| **증류수** | 중간 세정 | NaOCl+EDTA/CHX/QMix 직접 접촉 시 **PCA 침전 방지 필수** |
| **QMix / CHX** | 최종 세척 (잔류 항균) | NaOCl과 직접 혼합 금지 |

#### 4-3. 내원간 약제 — 선택적 도구

| 약제 | 적응증 | 핵심 |
|---|---|---|
| **CH (수산화칼슘)** | 1차 표준 | ~99.5% 미생물 감소 + 항염 |
| **TAP (삼중항생제 페이스트)** | E. faecalis 표적·재치료 | 최강 항균, 단 항생제 스튜어드십 한계 |
| **TAPC / 나노** | 48–72h 통증 완화 | 빠른 진통 |
| **Ledermix** | 급성 통증 | 최속 진통 |

> 내원간 약제는 농양·대형병소·재치료(E. faecalis 의심)에 **선택적** — 단회치료로 충분 (Wong 2015, Rossi-Fedele 2023).

#### 4-4. 임상 세정 프로토콜 (10단계)

```
1. NaOCl 1–6% + PUI 활성화 (1–3분) → 유기질 용해 + 항균
2. 증류수 중간 flush → PCA 침전 방지
3. 킬레이트제 (EDTA 17% 또는 HEDP) + PUI (1분) → 도말층 제거
   └─ 근첨 도말층 강조 시: 7% 말레산 (1–3분 한정)
4. 증류수 final flush
5. (옵션) QMix 또는 CHX 최종 세척 → 잔류 항균
   └─ NaOCl과 직접 접촉 금지 — 반드시 증류수 사이 세정
6. 페이퍼포인트 건조 시 NaOCl 잔류 없음 확인
7. 한 환자 1회 NaOCl 총량·접촉 시간 기록 (상아질 보호)
```

> 출처: [[overviews/irrigation-activation-comparison]], Orozco-Gallego 2025, Kumar 2023, Fortea 2024, Shalavi 2021, Fiegler-Rudol 2025, Ardila 2026

## Stage 5 — 근관충전 (Obturation)

### 핵심: AC까지 dense fill, extrusion 없음

#### 5-1. 종지점 — 5편 landmark 수렴

| 논문 | 핵심 결과 |
|---|---|
| Schaeffer 2005 (meta-analysis) | 0–1mm short(A군)이 past-apex(C군)보다 **성공률 +28.8%** |
| Chugal 2003 (prospective, 4yr) | WL은 **진단 종속** — AP에서 1mm 손실마다 실패 +14% |
| Ng 2007 Part 2 (SR+MA, 63편) | RA 2mm 이내 충전 + void 없음 + extrusion 없음 → 유의 성공률 향상 |
| Ricucci 2011 (prospective, 5yr) | 전체 88.6%/90.3%; **과충전 성공률↓**, 질환 중증도 지배 |
| Sjogren 1990 (cohort, 8–10yr) | 전장 기구조작 + root filling level 유의; 술전 상태 최상위 인자 |

#### 5-2. 충전 기법 — 장기 동등

Mushtaq 2026 (SR+MA, **84편·11,965표본**): 기법 간 유의한 차이는 **24개월에만** (CLC vs SC β=+5.0%, p=0.021; CB vs SC β=+7.5%, p=0.011), **3년 이후 수렴**. 바이오세라믹 실러+단일콘도 종래 술식 대비 장기 이점 없음.

| 기법 | 약자 | 특징 |
|---|---|---|
| 냉측방가압 | CLC | 가장 오래된 표준, 24개월 SC 대비 소폭 우위 |
| 온수직가압 | WVC | 밀폐 우수, 숙련 필요 |
| 온측방가압 | WLC | WVC 대안 |
| 단일콘 | SC | 바이오세라믹 실러와 조합 증가, 장기 동등 |
| 캐리어기반 | CB | 24개월 SC 대비 소폭 우위(+7.5%), 3년 이후 수렴 |

#### 5-3. 술전 진단별 충전 전략 통합

| 술전 진단 | WL 목표 | 충전 원칙 |
|---|---|---|
| 생활치수 / 무병소 | AC에서 다소 물러남 (RA−1mm) | 과기구조작 회피, dense fill |
| 괴사 + AP | AC 근접 (RA−0.5mm) | 감염된 근단부 소독 필수 |
| 모든 경우 | **void 없음 · extrusion 없음** | 과충전 성공률↓ |

> 출처: [[overviews/obturation-length-outcome-overview]], [[endodontics/obturation/mushtaq-2026-obturation-techniques-endodontic-outcomes-srma]], Schaeffer 2005, Chugal 2003, Ng 2007, Ricucci 2011

## 최종 보철 (Coronal Restoration) — 최대 예후 인자

| 항목 | 근거 |
|---|---|
| 최종 보철 적합도가 **치유의 최대 결정 인자** | [[endodontics/irrigation/llena-2020-outcome-root-canal-treatments-provided]] (585치아, 후향) |
| coronal leakage가 치유 실패 주원인 | Llena 2020 |
| 세정·충전 품질과 동등한 중요도 | Llena 2020, Ng 2007 |

> 임시 수복도 밀폐 필수 — 근관치료 전후로 **coronal seal이 최대 예후 조절 변수**.

## 포괄 프로토콜 한눈에 보기

```
┌─────────────────────────────────────────────────────────┐
│  1. 해부 평가 (PA ± CBCT)                                 │
│     → 단순: TEC 직선접근 / 복잡: 유도근관치료 고려          │
├─────────────────────────────────────────────────────────┤
│  2. 접근와동 (TEC 표준)                                    │
│     → 치수강 지붕 제거 + 경부 돌출 제거 → 직선 진입          │
├─────────────────────────────────────────────────────────┤
│  3. Glide path → Rotary/Reciprocating NiTi 형성           │
│     → 보존적 형상 목표 (상아질 벽 두께 보존)                  │
├─────────────────────────────────────────────────────────┤
│  4. 작업장 측정 (EAL + 방사선)                              │
│     → 전치: "0" −0.85mm / 구치: −0.70mm                   │
│     → 진단별 조절: 생활치수 약간 물러남 / 괴사+AP 근첨 근접   │
├─────────────────────────────────────────────────────────┤
│  5. 세정·소독 (핵심 병목)                                   │
│     → NaOCl + PUI → 증류수 → EDTA + PUI → 증류수 flush   │
│     → (옵션) QMix/CHX 최종세척                             │
│     → 내원간 약제는 선택적 (농양·대형병소·재치료)             │
├─────────────────────────────────────────────────────────┤
│  6. 건조 → 충전 (SC/CLC/WVC 등)                           │
│     → 진단 기준 WL까지 dense fill, extrusion 없음          │
│     → 기법은 술자 숙련도·해부에 선택 (장기 차이 없음)        │
├─────────────────────────────────────────────────────────┤
│  7. 최종 보철 (coronal restoration)                        │
│     → 밀폐 적합도 = 최대 예후 인자 (Llena 2020)            │
└─────────────────────────────────────────────────────────┘
```

## 미해결 영역 · 추가 근거 필요

- **MIA 임상 RCT**: 파절 저항 이득의 임상 확인 (현재 전부 in vitro)
- **레이저 활성화 outcome-level RCT**: Fiegler-Rudol 2025 대리지표 일관 우위, 단 12개월 치유 RCT 부재 (Doğan 2024 NS)
- **PUI vs ANP 임상 치유 head-to-head RCT**: 도달은 ANP 우위, 치유는 PUI 우위 — 어느 쪽이 실제 결과를 결정하는지 미확정
- **WL 진단별 RCT**: Chugal 2003의 진단-stratified WL 효과를 현대 프로토콜로 재검증
- **최종 보철 품질 vs 치유 인과관계**: Ricucci(무영향) vs Ng(유의) 충돌 미해결
- **상아질 손상 → 파절 임상 연결**: 세정제 미세경도 감소 ↔ 실제 치근 파절률 데이터 부족
