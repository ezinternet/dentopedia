## 한국어 핵심요약

> [!summary] 한국어 핵심요약
> - 근관 성형(canal shaping) 14편 종합 — bench(in-vitro/ex-vivo) 9편을 다섯 축으로 묶고, **2026-11-24 축 6으로 임상 파절률 5편**(SR+메타회귀 1·전향 3·후향 1)을 더해 bench→임상 연결을 처음 확보. 치유율·술후 통증 같은 다른 임상 종점은 여전히 0건.
> - 결론 한 줄: "곡률이 복잡한 근관에서 어떤 file을, 몇 번까지, 어떤 kinematics로 쓸 것인가"로 수렴.
> - 축1 글라이드패스(glide path) 기하: 수동 SS K-file이 어떤 rotary pathfinder보다 transportation(이송)이 크고(Aflaki 2020, Aminsobhani 2022, p<0.001), rotary 시스템끼리는 동등 → 선택 기준은 비용·가용성. 곡관에서 수동 K-file은 1차 선택에서 배제.
> - 축2 생물학적 비용: 수동·연속회전·왕복 세 kinematics 모두 근첨공 너머로 세균을 압출(bacterial extrusion)(Pui-Yii 2021) — transportation을 줄여도 압출은 0이 안 됨.
> - 축3 본 성형 곡관 보존: low-taper 트루나토미(TruNatomy)가 3·5mm 레벨 이송·삭제량·시간 모두 최소(Kim 2021), 프로테이퍼 골드(ProTaper Gold, PTG)는 apical curve에서 이송 최대.
> - 축4 순환 피로(cyclic fatigue): 곡률 복잡도(double curve·S-shape)가 file 수명을 결정하는 1차 stressor(p<0.05); EdgeEvolve·EdgeTaper Platinum > PTG ≈ TruNatomy. PTG가 여러 연구에서 비교군 하한.
> - 축5 멸균: 오토클레이브(autoclave) 멸균은 heat-treated NiTi의 피로를 약화시키지 않고 일부는 강화(Özyürek 2017, Almohareb 2023, 두 독립 trial 수렴) — R-phase 재배열 추정.
> - **축6 임상 파절률 (2026-11-24 추가)**: 통합 NiTi 파절률 2.27%, 회전 2.43% vs 왕복 1.0% — **운동방식 간 유의차 없음**; 예측인자는 치료 치아 수·술자 미숙·대구치 (Gomes 2021, SR+메타회귀). 실제 코호트에서 치아당 3.6–4.4%, 대구치 6.9–9.6%, 파절의 72–84%가 근첨 1/3 (Machado 2018·Eskibağlar 2023). 폐기된 ProTaper Next 571개 중 결함 13.83%(파절 7.53%), **X1 17/.04는 파절 19.87%**, 파절의 79%가 순환 피로 (Fernández-Pazos 2018) → bench의 "곡률이 1차 stressor"가 임상에서 재현됨. Bueno 2020(WaveOne Gold, 대구치 750개)은 보유 텍스트에 파절률 수치 없음.
> - 불일치 플래그: PTG가 Özyürek에서는 autoclave로 NCF↑, Almohareb에서는 중립 — file size/taper·cycle 수·canal 기하 차이 때문에 "PTG는 autoclave로 강화"라 단정 불가.
> - 임상 결정 ladder: 글라이드패스는 비용 기준 rotary 1종 / 본 성형은 곡관에선 low-taper(TruNatomy) 우선 / file 폐기 기준은 멸균 횟수가 아니라 사용 횟수+곡률 노출 — **소형 파일(ProTaper Next X1급)은 1회용 + 사용 전 ≥10배 확대 검사** / heat-treated NiTi는 표준 autoclave 그대로 / 대구치·근첨 1/3·중등도 이상 곡률·미숙 술자가 겹치면 파절 고위험.
> - 한계: RCT 0건, bench 축은 resin block 의존·단일 균종(E. faecalis)·단근치; 임상 파절률은 이제 보유하나 술자층이 학생~전문의로 이질적이고, 치유율·flare-up·술후 통증 연결 데이터는 여전히 없음.

## Three-line Summary

Synthesis of 14 canal-shaping papers (9 in-vitro/ex-vivo bench studies + 5 clinical fracture-incidence studies added 2026-11-24): manual stainless-steel K-files cause significantly greater glide-path transportation than any rotary pathfinder (rotary systems are mutually equivalent — Aflaki 2020, Aminsobhani 2022), yet no kinematics avoids apical bacterial extrusion (Pui-Yii 2021); for main shaping, low-taper TruNatomy best preserves curved canals (transportation, volume removed, time all minimized; Kim 2021), while ProTaper Gold is the comparator floor for both transportation and cyclic fatigue.

Autoclave sterilization does not weaken heat-treated NiTi and may strengthen it (two independent trials: Özyürek 2017, Almohareb 2023 — attributed to R-phase rearrangement), with the sole caveat that ProTaper Gold showed inconsistent autoclave effects across studies (size/taper/cycle differences); curvature complexity (double/S-curve) is the primary cyclic-fatigue stressor, and EdgeEvolve/EdgeTaper Platinum outperform ProTaper Gold ≈ TruNatomy in fatigue resistance.

Clinical fracture data now corroborate the bench stressor: pooled NiTi fracture 2.27% with rotary vs reciprocating not significantly different, predicted by molars, operator inexperience and case volume (Gomes 2021), concentrated in molars (6.9–9.6%) and the apical third (72–84%), and 79% cyclic-fatigue in origin with small ProTaper Next X1 files fracturing at 19.87% (Fernández-Pazos 2018). Clinical takeaway (healing and post-op pain endpoints still absent) — glide path: choose any rotary (cost basis), exclude manual SS K-file in curved canals; main shaping: prefer low-taper in complex curvature; file retirement SOP: track use-count + curvature exposure, not sterilization cycles; heat-treated NiTi: standard autoclave is safe; small-size files: single use with ≥10× inspection.

## 세줄요약

근관 성형(canal shaping) 14편 종합(bench 9 + 2026-11-24 추가 임상 파절률 5): 글라이드패스(glide path) 단계에서 수동 SS K-file이 어떤 rotary pathfinder보다 transportation이 크고, rotary 시스템끼리는 동등(Aflaki 2020, Aminsobhani 2022) — 단 어떤 kinematics도 apical 세균 압출(bacterial extrusion)을 피하지 못함(Pui-Yii 2021).

본 성형 단계에서 low-taper 트루나토미(TruNatomy)가 곡관 보존·시간·삭제량 모두 최소이고 프로테이퍼 골드(ProTaper Gold, PTG)는 transportation·cyclic fatigue 양쪽에서 비교군 하한(Kim 2021); 오토클레이브(autoclave) 멸균은 heat-treated NiTi의 피로를 약화시키지 않고 일부 강화(Özyürek 2017, Almohareb 2023, R-phase 재배열 추정); 곡률 복잡도(double curve·S-shape)가 file 수명의 1차 stressor.

임상 파절률(축 6)이 bench의 곡률 stressor를 재현 — 통합 파절 2.27%, 회전 vs 왕복 유의차 없음(Gomes 2021), 대구치 6.9–9.6%·근첨 1/3에 72–84% 집중, 파절의 79%가 순환 피로이고 ProTaper Next X1은 19.87%(Fernández-Pazos 2018). 임상 결론(치유·술후 통증 종점은 여전히 없음) — 글라이드패스는 rotary 1종 비용 기준 선택; 본 성형 곡관은 low-taper 우선; file 폐기 SOP는 멸균 횟수 아닌 사용 횟수+곡률 노출 기준; heat-treated NiTi는 표준 autoclave 그대로; 소형 파일은 1회용 + ≥10배 확대 검사.

## Summary
이 페이지는 `endodontics/shaping` 카테고리의 bench 9편과 임상 파절률 5편을 묶는다 (bench는 아래 세 영역, 임상은 축 6): glide-path 단계의 기하학적 transportation과 생물학적 비용, 본 성형(main shaping) 단계의 file 선택과 곡관 보존, 그리고 NiTi 합금의 cyclic fatigue와 autoclave 멸균 상호작용. 세 축은 독립 주제처럼 보이지만 하나의 임상 결정 — "곡률이 복잡한 근관에서 어떤 file을, 몇 번까지, 어떤 kinematics로 쓸 것인가" — 로 수렴한다.

축 1–5의 9편은 전부 in-vitro/ex-vivo이므로 그 결론은 bench 수준에서 일관될 뿐 임상 적용은 외삽이다. 축 6(2026-11-24 추가)의 임상 파절률 5편이 그 외삽 중 "곡률·근첨부가 파절을 부른다"는 부분만 임상으로 확인해 준다. 근관 세정(최종 세척) 단계는 경계 밖이다 — 예컨대 QMix 3중 작용 최종 세척은 17% EDTA와 동등한 도말층 제거를 보이나 NaOCl과 사이에 증류수 세척을 넣지 않으면 파라클로로아닐린 (PCA) 침전이 생긴다는 안전 제약이 있다 ([[endodontics/irrigation/shalavi-2021-qmix-root-canal-irrigation-overview]]).

## Results

### 축 1 — Glide Path Geometry: 수동 vs Rotary
두 독립 연구가 기질을 달리해 같은 결론에 도달한다. Aflaki 2020 (천연 dentin, 하악 대구치 MB, 25–45° 곡률, n=51, CBCT)에서 수동 SS K-file은 3 mm·9 mm 레벨에서 PathFile·Scout RaCe보다 유의하게 큰 transportation을 냈고, 두 rotary는 동등했다. Aminsobhani 2022 (S-shaped resin block, n=100, 5군)는 이를 확장 — 수동 K-file이 apical·middle third에서 가장 큰 deviation (p<0.001), Scout RaCe·One G·PathFile·GPS 4종 rotary는 서로 통계적 차이 없음. Kim 2017 (인공치아 MB2, n 소규모)은 기구 간 차이가 있는 지점을 따로 짚는다 — ProGlider가 PathFile·One G보다 상아질 삭제량(중량 감소)이 유의하게 많았지만(p<0.05), 이어진 WaveOne 본 성형의 최대 토크·총 스트레스에는 글라이드패스 유무·기구 종류 간 차이가 없었다 ([[endodontics/shaping/kim-2017-efficiency-niti-glide-path-preparation]]). 즉 pathfinder의 기하 차이는 삭제 효율에는 보이지만 본 성형 기구의 비틀림 부하 감소로 이어진다는 근거는 없다.

함의: glide-path rotary pathfinder 간 transportation 차이는 무시 가능 → 선택 기준은 비용·가용성. 수동 K-file은 곡관에서 1차 선택에서 배제. [확인] (bench 일관성 기반)

### 축 2 — Glide Path의 생물학적 비용
Pui-Yii 2021 (발치 단근치, E. faecalis 접종)은 기하 연구가 무시하는 차원을 측정한다: 수동 K-file·One G 연속회전·WaveOne Gold Glider 왕복 — 세 kinematics 모두 apical foramen 너머로 측정 가능한 세균을 압출했다. 즉 rotary로 transportation을 줄여도 생물학적 압출은 0이 되지 않는다. flare-up 위험군에서는 file 선택과 무관하게 apical patency 관리와 압출 최소화 술기가 필요. [미검증]

### 축 3 — 본 성형 file의 곡관 보존
Kim 2021 (S-shaped resin, n=60, PTG/WaveOne Gold/TruNatomy)에서 minimal-taper TruNatomy가 3·5 mm 레벨 transportation 최소, 삭제량 최소, 시간 최단. ProTaper Gold는 apical curve(2–3 mm)에서 transportation 최대. 곡률이 복잡할수록 taper가 낮은 시스템이 곡관 중심을 유지한다는 방향. [확인]

윤활제 선택도 이송에 관여한다. Whitbeck 2015 (발치치, micro-CT, 회전 NiTi)에서 17% EDTA 용액은 생리식염수보다 이송을 키우지 않았고, 킬레이트 페이스트 RC-Prep은 식염수·EDTA 모두보다 이송이 유의하게 작았다; 근관 부피 증가는 EDTA가 최대 ([[endodontics/shaping/whitbeck-2015-edta-preparations-rotary-canal-instrumentation]]). 킬레이트제가 근첨 이송을 악화시킨다는 우려는 bench 근거상 기각되며, 페이스트형은 오히려 줄일 수 있다.

### 축 4 — NiTi Cyclic Fatigue & 곡률 stressor
ProTaper Gold는 여러 연구에서 "비교군 하한" 역할을 한다. Khalil 2019 (single vs double curvature, n=15/group)에서 EdgeEvolve가 PTG보다 cyclic fatigue·굴곡 유연성·표면 평활도(AFM Ra) 모두 우수 — Ni/Ti 조성은 동일한데도. 또한 double-curvature 근관은 두 시스템 모두 fatigue resistance를 낮췄다(p<0.05). Almohareb 2023에서도 EdgeTaper Platinum > ProTaper Gold ≈ TruNatomy. 정리하면 곡률 복잡도(double curve·S-shape)가 file 수명을 결정하는 1차 stressor이고, file 간 차이는 단순 근관에서 희미해지고 복잡 근관에서 증폭된다. [확인]

### 축 5 — Autoclave 멸균은 NiTi를 약화시키지 않는다
Özyürek 2017 ([[endodontics/shaping/ozyurek-2017-protaper-cyclic-fatigue-sterilization]]; ProTaper Universal/Next/Gold, n=240, 4 멸균 프로토콜): baseline에서 PTG > PTU·PTN, 그리고 10회 pre-test autoclave가 PTN·PTG의 number of cycles to failure(NCF)를 유의하게 증가. Almohareb 2023: EdgeTaper Platinum은 1회·10회 autoclave 후 NCF 유의 증가, ProTaper Gold·TruNatomy는 멸균 중립(neutral). 방향: heat-treated NiTi의 routine autoclave는 fatigue 손실 없음, 일부는 합금 aging(R-phase 재배열 추정)으로 강화. [확인] (두 독립 trial 수렴)

**불일치 플래그**: ProTaper Gold가 Özyürek 2017에서는 autoclave로 NCF↑, Almohareb 2023에서는 중립. 원인 후보 — file size/taper 차이(Almohareb는 PTG 25/.08), cycle 수(1/5/10 vs 10), 시험 canal 기하 차이. 동일 명칭 file이라도 단면·테이퍼가 다르면 결과가 갈릴 수 있어, "PTG는 autoclave로 강화된다"고 단정 불가. [미검증]

### 축 6 — 임상 파절률: bench stressor가 임상에서 재현된다 (2026-11-24 추가)
가장 넓은 근거는 Gomes 2021 SR+메타회귀다: 임상 NiTi 파절 통합 2.27%, 회전 2.43% vs 왕복 1.0%로 **운동방식 간 차이는 통계적으로 유의하지 않았고**, 파절률을 높인 예측인자는 치료 치아 수·술자 미숙·대구치였다 ([[endodontics/shaping/gomes-2021-clinical-fracture-incidence-rotary-reciprocating]]). 개별 코호트가 같은 지형을 보여준다. 대학원생이 ProTaper Universal로 치료한 1,031치아(2,355근관, 5년 후향)에서 치아당 4.4%·근관당 1.9%, 파절의 66.7%가 하악, 84.4%가 근첨 1/3, 하악 대구치 8.8–9.6% ([[endodontics/shaping/machado-2018-incidence-protaper-universal-system]]). 학생 154명이 K-file과 왕복 NiTi(Endoart Expert Gold)로 치료한 2,168치아(전향)에서 전체 3.6%, 왕복 NiTi가 수동 파일의 약 3배(59 vs 20건), 대구치 6.9%, 근첨 1/3 72.1%, 파절의 44.3%가 중등도·38%가 고도 곡률 근관 ([[endodontics/shaping/eskibaglar-2023-fracture-prevalence-instruments-used]]). 전문의 6명이 12개월간 폐기한 ProTaper Next 571개(전향)에서는 결함 13.83%(파절 7.53%)였고 **X1 17/.04가 파절 19.87%(32/161)·결함 31.67%**, 파절의 79.07%가 순환 피로 기전이었다 ([[endodontics/shaping/fernandezpazos-2018-fracture-deformation-protaper-next]]). 숙련 전문의 3명의 WaveOne Gold 대구치 750개(2,691근관, 곡률 <45°, 기구 1,104개) 전향 연구는 설계만 보유하고 있으며 파절률 수치는 보유 텍스트에 없다 ([[endodontics/shaping/bueno-2020-fracture-incidence-waveone-gold-files]]) — 숫자를 인용하지 말 것.

읽는 법: ① 축 4의 bench 결론("곡률 복잡도가 1차 stressor")은 임상에서 대구치·근첨 1/3·중등도 이상 곡률 집중과 순환 피로 79%로 재현된다. ② bench의 왕복 우위는 임상 통합에서 유의하지 않다 — 왕복 1.0% vs 회전 2.43%의 방향은 있으나 결정 근거로 쓰기엔 부족. Eskibağlar의 "왕복 NiTi가 수동 파일의 3배"는 운동방식 비교가 아니라 NiTi vs 수동 비교이고 사용 빈도 보정이 없다. ③ 술자 경험은 Gomes·Machado에서 예측인자지만 Eskibağlar에서는 교육 단계 간 차이가 경계 수준(p=0.051) — 술자 범위가 학생층에 몰려 대비가 좁았던 탓으로 읽는다(추론). ④ 파일 크기도 변수다: 같은 시스템에서 가장 작은 X1이 파절·결함 최고 → "사용 횟수+곡률" 폐기 기준에 **크기**를 더해야 한다.

| 단계 | 권장 | 대안 / trade-off |
|---|---|---|
| Glide path (곡관) | rotary pathfinder 1종(비용 기준 선택) — transportation 동등 | 수동 K-file은 곡관에서 transportation 최대, 직선·넓은 근관에서만 허용. WaveOne Gold Glider 왕복은 단일 file 효율 ↔ 압출은 여전 |
| 본 성형 (S-shape·double curve) | low-taper 우선 — TruNatomy(곡관 보존·삭제 최소·시간 최단) | ProTaper Gold는 transportation 하한이나 가용성·익숙함 이점. EdgeEvolve/EdgeTaper Platinum은 fatigue·유연성 우위 |
| File 재사용 폐기 기준 | 사용 횟수 + 곡률 노출(double curve 1회=큰 stress)로 판단 | 멸균 횟수는 기준 아님 — autoclave는 fatigue 비악화·일부 강화 |
| 멸균 SOP | heat-treated NiTi는 표준 autoclave 그대로 | 멸균이 fatigue를 깎는다는 우려는 bench 근거상 기각 |
| 소형 파일 (ProTaper Next X1 17/.04급) | 1회용 + 매 사용 전 ≥10배 확대 검사 (Fernández-Pazos 2018: 파절 19.87%) | 임상 근거는 단일 대학 전향 코호트 — 다른 시스템 소형 파일로 일반화는 외삽 |
| 고위험 상황 인지 | 대구치 + 근첨 1/3 + 중등도 이상 곡률 + 미숙 술자 → 파절 위험 누적 (Gomes 2021, Machado 2018, Eskibağlar 2023) | 운동방식(회전 vs 왕복) 교체는 임상 통합상 유의한 감소 근거 없음 |
| 윤활제 | 17% EDTA 또는 킬레이트 페이스트 사용 가능 — 이송 비악화, 페이스트는 감소 (Whitbeck 2015) | bench 단일 연구 |

최종 판단은 원장 몫. 위 ladder의 기하·멸균 행은 bench 근거의 외삽이고, 파절 관련 행만 임상 파절률(축 6)에 근거한다. 치유율·술후 통증 직접 근거는 본 14편에 없음.

## 근거 한계 (전 축 공통)
- 축 1–5의 9편은 전부 in-vitro/ex-vivo. RCT 0건. 임상 근거는 축 6의 파절률 5편(SR+메타회귀 1·전향 3·후향 1)뿐이며 치유율·술후 통증 종점은 0건.
- resin block 의존(Aminsobhani·Kim·Khalil) — dentin 미세경도 미반영; Aflaki만 천연 dentin.
- 단일 술자·단일 기하 설계가 대부분.
- Pui-Yii는 단일 균종(E. faecalis)·단근치 — 다근치 대구치 multi-species biofilm 미모델.
- 임상 파절 코호트는 술자층(학생·대학원생·전문의)과 파절 정의(파절 vs 변형 포함)가 제각각이라 비율을 직접 비교하기 어렵다; Bueno 2020은 수치 미보유.
- flare-up·치유 연결 데이터 없음.

## Phase 2 확장 후보 (Stub)
- WaveOne Gold·Reciproc 등 reciprocation 본 성형 file의 transportation/fatigue 직접 비교 추가 시 축 3·4 보강.
- 임상 RCT(근관 성형 후 치유·술후 통증) ingest 시 "bench→임상" gap 메울 것 (파절률 축은 2026-11-24 부분 해소).
- Glide path 생략 vs 시행의 본 성형 file 파절률 영향 논문.
