## Three-line Summary

Cross-sectional pilot (n=186 dental students, Akdeniz University, Turkey) assessed Code Blue awareness via 10-item MCQ comparing preclinical 3rd-year vs. clinical 5th-year students.

Code Blue recognition was 70.4% overall; clinical students significantly outperformed preclinical (77.3% vs. 62.9%, p < 0.05); but 70.5% incorrectly classified vasovagal syncope as a Code Blue event, and only 7.4% correctly rejected all non-indicated scenarios.

Despite clinical exposure improving emergency code awareness, the high vasovagal syncope misclassification rate reveals a persistent and clinically dangerous gap requiring dedicated curriculum integration.

## 세줄요약

단면 파일럿 (n=186, 터키 아크데니즈 치과대학생) — 10문항 MCQ로 임상 전기 (3학년) vs 임상기 (5학년) 코드블루 인지도 비교.

코드블루 (Code Blue) 전체 인지율 70.4%; 임상기 77.3% > 전임상기 62.9% (p<0.05); 혈관미주신경성 실신 (Vasovagal Syncope)을 코드블루로 잘못 분류한 비율 70.5%, 비해당 시나리오를 **전부** 올바르게 기각한 비율은 7.4%에 불과.

임상 교육이 응급코드 인지도를 높이지만, 혈관미주신경성 실신의 과잉 코드 발동 위험은 임상적으로 위험한 격차 — 교육과정 내 체계적 통합이 필요.

## Study Design

| Item | Detail |
|---|---|
| Design | Cross-sectional descriptive pilot study |
| n | 186 students (53.2% female, 46.8% male) |
| Groups | 3rd-year preclinical vs. 5th-year clinical students |
| Instrument | 10-item MCQ: Code Blue indications, activation, response expectations |
| Analysis | Descriptive + chi-square; comparative statistics |
| Setting | Akdeniz University, Antalya, Turkey; academic year 2022–2023 |

| Outcome | 3rd Year (Preclinical) | 5th Year (Clinical) | p |
|---|---|---|---|
| Code Blue recognition | 62.9% | 77.3% | < 0.05 |

| Vasovagal syncope misclassified as Code Blue | 70.49% (combined) | — | — |
| All non-indicated scenarios rejected correctly | 7.38% | — | — |

**Overall Code Blue recognition**: 70.43%

## Critical Finding — Vasovagal Syncope Misclassification

70.5% of all students identified vasovagal syncope as a Code Blue event. This is clinically important:

- Vasovagal syncope is the **most common** dental emergency (up to 50% of all in-office events)
- It is self-limited, managed by positioning (Trendelenburg) and observation — NOT full Code Blue activation
- Inappropriate Code Blue calls: delay real emergency responses, cause patient/team anxiety, consume resources
- This finding suggests BLS knowledge (pressing buttons, doing compressions) is being misapplied to non-arrest scenarios

## Limitations

- Single-center pilot; small sample — limited generalizability
- 10-item questionnaire not validated
- Cross-sectional — causality of clinical exposure unclear
- Quiz-based only; no direct behavioral or skill observation
