## Why Ingested

Posterior mandibular ridge morphology directly determines safe implant axis orientation for delayed/staged placement — lingual undercut prevalence and concavity depth quantify the lingual plate perforation (LPP) risk that forces buccal tilt. This paper fills the gap noted in the wiki: no classification system covering IAC position + lingual concavity + ridge shape was previously ingested. Extends [[immediate-implant/anatomic-assessment/behfarnia-2025-anatomic-immediate-implant-mandibular-posterior]] (IAC safety distances, ridge type distribution) with a new CPDU framework applicable to all posterior mandibular implant therapy.

## Three-line Summary

Retrospective CBCT cross-sectional study (195 patients, 195 first-molar sites, Dubai) measuring posterior mandibular ridge morphology parameters to develop a new CPDU (Convergent/Parallel/Divergent + Undercut) classification that integrates ridge shape, lingual concavity depth/angle, and IAC position.

U-type (undercut) ridge was most prevalent (54.4% L, 52.1% R); CPDU adds a D-type (divergent: narrow base, wide crest, inherent undercut) with influential/non-influential modifier based on IAC proximity, distinguishing cases with lingual perforation risk that prior CPU systems missed.

CBCT is mandatory for posterior mandibular implant planning: D-type and U-I type ridges pose the highest lingual cortical plate perforation risk and require modified implant axis planning.

## 세줄요약

후향적 CBCT 단면연구(195명, 하악 제1대구치 부위) — 후방 하악 능선 형태 계측치(Wc·Wb·Vcb·Vb·Vc·설측 함몰 깊이·각도)를 기반으로 새로운 CPDU(수렴형/평행형/분기형 + 언더컷) 분류 시스템 개발.

언더컷형(U-type) 능선 가장 흔함(54.4%/52.1%); CPDU의 D형(분기형: 좁은 기저부+넓은 능선정+고유 언더컷)이 기존 CPU 분류의 맹점을 보완하고 하치조 신경관(IAC) 위치에 따라 influential/non-influential로 구분.

후방 하악 임플란트는 CBCT 필수: D형·U-I형 능선에서 설측 피질골 천공 (Lingual Plate Perforation, LPP) 위험 최고, 수정된 식립 방향 계획 필요.

## Key Contributions

- First classification to integrate ridge shape + lingual concavity depth/angle + IAC position into a single CPDU framework
- Introduces D-type (divergent) ridge — a distinct morphology with narrow base, wide crest, and inherent undercut that existing systems misclassify as U-type
- Adds influential (I) / non-influential (N) modifier: undercut above IAC in the implant path = I; otherwise N
- Quantifies concavity depth by undercut status: 1.72 mm (with) vs 0.61 mm (without) on left (p=0.001)
- Ridge type prevalence: U-type 54.4%, P-type 27.2%, C-type 18.5% (left)

## Methodology

- **Design**: retrospective cross-sectional, 195 CBCT volumes from 350 screened, single center (Dubai Health)
- **Imaging**: Sirona Galileos, 15×15×15 cm FOV, 0.15 mm voxel, 85 kVp, 28 mA
- **Inclusion**: age >19, missing mandibular first molar, ≥8 mm bone height, ≥3.5 mm crest width; no grafts, pathology, trauma
- **Measurements**: Wc (crest width), Wb (base width), Vcb (total height), Vb (below P point), Vc (above P point), concavity depth, concavity angle
- **Statistics**: Kolmogorov-Smirnov, Mann-Whitney, Kruskal-Wallis, Pearson/Spearman correlations, SPSS 29.0; STROBE checklist

## Key Results

**Ridge type distribution:**

| Ridge type | Left | Right |
|---|---|---|
| U (undercut) | 54.4% | 52.1% |
| P (parallel) | 27.2% | 33.5% |
| C (convergent) | 18.5% | 14.4% |

**Lingual concavity depth by undercut (Left/Right):**
- With undercut: 1.72 / 1.93 mm
- Without undercut: 0.61 / 0.71 mm (p<0.001)

**Lingual concavity depth by ridge type (Left/Right):**
- C-type: 1.19 / 1.16 mm
- P-type: 1.42 / 1.37 mm
- U-type: 1.89 / 2.27 mm (p=0.021 L, p<0.001 R)

**Alveolar ridge height above P point (undercut status):**
- With undercut: 17.53 / 17.78 mm
- Without: 12.59 / 15.17 mm (p=0.006 both)

**Modifiers:**
- Male > female: ridge height (p<0.001), height above P point (p<0.001)
- Age <40: greater crest width, greater ridge height
- First molar present: substantially greater crest width, ridge height, concavity depth (R)
- Nearly all U-type ridges show a lingual undercut

**CPDU classification steps:**
1. Shape: C (convergent), P (parallel), D (divergent)
2. Undercut: +U if present in C/P; inherent in D (skip step 2)
3. Influential status: I (above IAC, in implant path) or N (non-influential)

## Limitations

- Single center, single ethnicity (UAE); racial/ethnic variation in ridge morphology may affect generalizability
- Single investigator analysis (intraobserver only, no interobserver agreement)
- Only first-molar sites analyzed; second premolar and second molar not included
- No clinical outcome data; classification is preoperative risk stratification only
- Concavity angle showed no significant correlation with ridge type or undercut on left side

## Glossary

- **CPDU**: Convergent / Parallel / Divergent + Undercut — new 4-step classification for posterior mandible ridge morphology
- **D-type ridge**: narrow base, wide crest, inherent lingual undercut; not present in prior CPU classification
- **Point P**: most prominent point on lingual cortical plate, used as the pivot for concavity measurement
- **Line A**: horizontal line 2 mm coronal to superior IAC border; defines the depth limit for implant placement
- **Influential undercut (I)**: undercut located above IAC and in the planned implant path, posing LPP risk
- **LPP**: lingual plate perforation — the primary complication risk in posterior mandibular implant placement
