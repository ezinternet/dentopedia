## Why Ingested

치과대학생 코드블루 (응급코드) 인지도 조사 — 임상 전기 (3학년) vs 임상기 (5학년) 간 차이를 비교한 파일럿 연구. [[drug/medical-emergencies/aquino-2026-perceived-confidence-managing-medical-emergencies]] (자기 확신도)와 짝을 이뤄 교육과정 중 응급 준비도 발달 궤적을 보여준다.

## One-line Summary

Cross-sectional pilot (n=186 dental students, Turkey) found Code Blue awareness 70.4% overall, significantly higher in clinical (5th-year, 77.3%) vs. preclinical students (3rd-year, 62.9%), with critical misidentification of vasovagal syncope as Code Blue.

## 한줄요약

단면조사 파일럿 (n=186, 터키 치과대학생) — 코드블루 (Code Blue) 인지율 70.4%, 임상기 77.3% vs 전임상기 62.9% (p<0.05), 혈관미주신경성 실신 (Vasovagal Syncope)을 코드블루 상황으로 잘못 분류한 비율 70.5%.

## 1. Document Information

- Journal: European Journal of Dental Education, Vol. 30, Issue 4, pp. 1645–1650 (2026)
- Affiliation: Akdeniz University Faculty of Dentistry, Antalya, Turkey
- Study period: Academic year 2022–2023

## 2. Key Contributions

- First study assessing Code Blue awareness specifically among dental students
- Demonstrates that clinical exposure (5th year) improves Code Blue knowledge but gaps persist
- Identifies vasovagal syncope misclassification as Code Blue — 70.5% error rate (a common, manageable dental emergency being over-triaged as cardiac arrest)
- Only 7.38% correctly rejected ALL non-indicated Code Blue scenarios
- BLS content knowledge does not significantly differ between preclinical and clinical students

## 3. Methodology and Architecture

- **Design**: Cross-sectional descriptive pilot study
- **Population**: 186 dental students: 3rd-year (preclinical, n≈96) and 5th-year (clinical, n≈90)
- **Instrument**: 10-item MCQ assessing Code Blue indications, activation procedures, response expectations
- **Analysis**: Descriptive + comparative statistics; chi-square for group comparisons
- **Setting**: Akdeniz University, Antalya, Turkey

## 4. Key Results and Benchmarks

- **Overall Code Blue recognition**: 70.43%
- **Most recognized code**: Code White (82.26%)
- **5th-year vs. 3rd-year Code Blue awareness**: 77.3% vs. 62.9% (p < 0.05)
- **Vasovagal syncope misclassified as Code Blue**: 70.49%
- **All non-indicated scenarios correctly rejected**: Only 7.38%
- **BLS knowledge difference between years**: NS (p = 0.8153)

## 5. Limitations and Future Work

- Single-center pilot; small sample — generalizability limited
- No validated instrument (10-item questionnaire, pilot design)
- Cross-sectional — cannot determine if clinical training caused improved Code Blue awareness
- No objective skill assessment — self-reported or quiz-based only
- Multi-center studies recommended by authors

## 6. Related Work

- Turkey mandated Code Blue in all healthcare facilities since 2011
- Code Blue protocol and BLS training in dental schools — limited prior literature
- aquino-2026: perceived confidence in managing medical emergencies, dental students (Brazil)

## 7. Glossary

- **Code Blue**: Universal hospital emergency response code for cardiopulmonary arrest
- **Code White**: Emergency code for violence/security incidents (most recognized in this study)
- **Vasovagal syncope**: Fainting from parasympathetic activation; NOT a Code Blue indication (it is self-limited and managed with positioning)
