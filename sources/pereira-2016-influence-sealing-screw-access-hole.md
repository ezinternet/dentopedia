## Why Ingested

임상의가 문의한 "스크류 접근홀 (Screw Access Hole, SAH) 실링 프로토콜"의 정확한 chairside 술식(산화알루미늄 air-abrasion → 10% 불화수소산 etching → silane → bonding agent → 코튼펠렛+P-60 레진콤포지트)을 제공하는 벤치 연구이며, SAH 실링이 나사유지 보철물의 파절저항 (Fracture Resistance)을 저하시키지 않음을 보여준다. [[prosthetic-materials/abutment-screw/hamed-2020-screw-vs-cement-implant-sr]]가 제시한 "SR 나사유지 방식이 기계적으로 안전한 선택"이라는 결론을 다른 각도(SAH 실링 유무의 기계적 영향)에서 독립적으로 뒷받침한다.

## Three-line Summary

In vitro mechanical study (n=30 implant-retained mandibular molar metal-ceramic restorations via UCLA abutments, 3 groups of 10: SRS = screw-retained with SAH sealed, SRNS = screw-retained with SAH unsealed, CR = cement-retained) comparing static fracture resistance.

SAH sealing protocol: aluminum-oxide air-abrasion → 10% hydrofluoric acid etch → silane coupling agent → bonding agent → cotton pellet filling → P-60 resin composite restoration; CR specimens cemented with RelyX U100; load applied via a 6.0 mm spherical-tip rod on buccal/lingual cusps at 0.5 mm/min crosshead speed until fracture (one-way ANOVA + Dunnett test, p<0.05; failure mode by SEM).

No significant difference in fracture resistance was found between the two screw-retained groups (SRS vs SRNS); the cement-retained (CR) group showed the highest mean fracture resistance — sealing the SAH does not compromise the mechanical strength of screw-retained implant restorations.

## 세줄요약

체외(in vitro) 기계적 실험 (UCLA 지대주 기반 임플란트 지지 하악 구치 금속-도재 보철물 n=30, 3군 각 10개: SRS=스크류 접근홀 (Screw Access Hole, SAH) 실링한 나사유지, SRNS=SAH 미실링 나사유지, CR=시멘트유지) 정적 파절저항 (Fracture Resistance) 비교.

SAH 실링 프로토콜: 산화알루미늄 air-abrasion → 10% 불화수소산(Hydrofluoric Acid, HF) etching → 실란(silane) 커플링제 → 본딩제 → 코튼펠렛 충전 → P-60 레진콤포지트 수복; CR군은 RelyX U100으로 접착; 직경 6.0mm 구형 팁 로드로 협·설측 교두 경사면에 0.5mm/min 크로스헤드 속도로 파절까지 정적 하중 부하(일원분산분석+Dunnett 검정, p<0.05; 파절양상은 주사전자현미경(SEM) 관찰).

나사유지 두 군(SRS vs SRNS) 간 파절저항 유의차 없음; 시멘트유지(CR)군이 평균 파절저항 최고치 — SAH 실링은 나사유지 임플란트 보철물의 기계적 강도를 저하시키지 않음.

## 2. Key Contributions
- Provides an explicit, reproducible chairside SAH restoration protocol (air-abrasion → 10% HF etch → silane → bonding → cotton pellet + P-60 composite)
- Demonstrates SAH sealing status (sealed vs unsealed) does not significantly alter screw-retained restoration fracture resistance
- Confirms cement-retained restorations retain a mechanical fracture-resistance advantage over screw-retained restorations in this model

## 3. Methodology and Architecture
- **Design**: In vitro comparative mechanical study (bench), 3 parallel groups
- **n**: 30 implant-retained mandibular molar restorations (10 per group: SRS, SRNS, CR)
- **Outcomes**: Static fracture resistance (N, via universal testing machine, crosshead 0.5 mm/min, 6.0 mm spherical-tip loading rod on buccal+lingual incline cusps); failure mode via SEM

## 4. Key Results and Benchmarks
- No statistically significant difference in fracture resistance between SRS (SAH sealed) and SRNS (SAH unsealed) groups
- CR group showed the highest mean fracture resistance among the three groups
- Abstract does not report exact mean/SD fracture-resistance values in Newtons for each group — only the statistical comparison outcome (p<0.05, ANOVA + Dunnett)

## 5. Limitations and Future Work
- Abstract-only source: exact numeric fracture-resistance values, SEM failure-mode categorization detail, and confidence intervals are not available without the full text
- In vitro bench model (mandibular molar UCLA-abutment restorations only) — generalizability to other tooth positions/abutment systems not established
- Static vertical loading protocol does not simulate cyclic fatigue or oblique/lateral functional loading over time

## 6. Related Work
- hamed-2020 (screw vs cement-retained SR): independent SR comparing SR/CR complication profiles; this bench study reinforces that SR mechanical performance is not compromised by SAH sealing

## 7. Glossary
- **SAH**: Screw Access Hole — the occlusal opening in a screw-retained restoration through which the retaining screw is accessed/tightened
- **SRS**: Screw-Retained, Sealed (SAH sealed group)
- **SRNS**: Screw-Retained, Not Sealed (SAH unsealed group)
- **CR**: Cement-Retained restoration group
