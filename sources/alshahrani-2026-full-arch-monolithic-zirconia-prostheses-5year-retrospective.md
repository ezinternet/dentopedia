## Why Ingested

Largest single-center retrospective on full-arch monolithic zirconia CAFIP failures (n=3300) — provides real-world laboratory failure spectrum and 5-year survival data that complements RCT evidence, extending [[wiki/implants/full-arch/tomar-2026-prosthetic-complications-complete-arch-umbrella]] and [[wiki/prosthetic-materials/waltenberger-2025-zirconia-implant-dentistry-guideline]].

## Three-line Summary

Retrospective cross-sectional analysis of 3300 screw-retained 3Y-TZP monolithic zirconia complete arch fixed implant-supported prostheses (CAFIPs) manufactured by a Dubai commercial dental laboratory (August 2019–August 2024); maxillary n=1900, mandibular n=1400.
5-year cumulative survival rate 91.67%; leading failure: framework fractures (n=38, primarily insufficient vertical space); ceramic chipping n=4 (mainly mandibular over-layering); 0 titanium cylinder debonding/fractures; failure rate trend: 2 events (year 1) → 14 events (year 5).
Full-arch monolithic ZrO₂ prostheses show excellent durability; framework design and vertical space adequacy are critical failure determinants; Ti component reliability is not a concern.

## 세줄요약

후향적 횡단면 연구, 3300개 나사유지형 3Y-TZP 모놀리식 지르코니아 전악 임플란트 고정성 보철물(Complete Arch Fixed Implant-Supported Prosthesis, CAFIP), 두바이 치과기공소(2019.8–2024.8); 상악 1900개, 하악 1400개.
5년 누적 생존율 91.67%; 주요 실패: 프레임워크 파절(n=38, 수직 공간 부족이 주인), 도재 칩핑(n=4, 하악 과잉 베니어 주), 티타늄 실린더 탈락·파절 0건; 실패 추이: 1년 2건 → 5년 14건으로 증가.
전악 단일체 지르코니아 보철 내구성 우수; 프레임워크 디자인·수직 공간 확보가 실패 결정 인자; Ti 부품 신뢰성은 우려 없음.

## Key Contributions

- Largest dataset (n=3300) on full-arch monolithic ZrO₂ CAFIP laboratory failures with 5-year life table analysis
- 5-year cumulative survival 91.67% — consistent with expected ZrO₂ full-arch performance
- Framework fracture (n=38) is primary failure mode; insufficient vertical space is top risk factor
- Ceramic chipping minimal (n=4) when limited to gingival area — supports minimal veneering strategy
- Zero titanium cylinder failures — screw-retained Ti component interface is mechanically reliable
- Failure rate increases year-on-year (2 → 14 events per year) — concerning trend for long-term durability

## Methodology

- **Design**: Retrospective cross-sectional study; laboratory records analysis
- **Setting**: Commercial dental laboratory, Dubai, UAE
- **n**: 3300 CAFIPs (maxillary 1900, mandibular 1400)
- **Material**: 3Y-TZP monolithic zirconia; veneered porcelain restricted to gingival area only; screw-retained
- **Period**: August 2019 – August 2024
- **Inclusion**: Remakes due to technical/material failure only (clinician/patient-driven returns excluded)
- **Analysis**: Life table approach for survival; failure mode categorization
- **Exclusion**: Clinician- or patient-driven interventions (to avoid bias)

## Key Results

| Metric | Value |
|---|---|
| Total CAFIPs | 3300 |
| 5-year cumulative survival | 91.67% |
| Framework fractures | 38 (primary failure) |
| Ceramic chipping | 4 |
| Ti cylinder debonding/fracture | 0 |
| Year 1 failure events | 2 |
| Year 5 failure events | 14 |

- Framework fractures associated with insufficient vertical space and suboptimal design
- Chipping confined to mandibular prostheses with excessive ceramic layering
- Maxillary vs mandibular specific failure rates not separately reported in abstract

## Limitations

- Retrospective laboratory records — no clinical data (MBL, peri-implant parameters, implant survival)
- Single-laboratory, single-region data (Dubai); generalizability limited
- Patient-level clinical complications not captured — only laboratory-return failures
- Increasing failure trend (2 → 14 events/year) warrants prospective clinical validation
- Author affiliations and conflict-of-interest details not available from abstract

## Glossary

- **CAFIP (Complete Arch Fixed Implant-Supported Prosthesis / 전악 임플란트 고정성 보철물)**: 전악 결손 환자에게 임플란트로 지지되는 전악 고정성 보철물
- **3Y-TZP (3몰% 이트리아 안정화 지르코니아)**: 가장 강도 높은 지르코니아 등급; 단일체 전악 보철에 사용
- **Framework fracture (프레임워크 파절)**: 지르코니아 내부 구조물의 파절; 주로 수직 공간 부족 시 발생
- **Life table analysis (생명표 분석)**: 누적 생존율 시간에 따른 산출 방법
