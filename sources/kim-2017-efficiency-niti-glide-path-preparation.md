## Why Ingested

글라이드 패스 형성용 니켈-티타늄 파일(PathFile, One G, ProGlider)의 삭제 효율과 성형 시 토크 발생을 인공 치아(Dentalike)를 이용해 비교한 예비 연구로, 근관 치료 전 글라이드 패스 형성 기구 선택의 근거 자료로 인제스트. [[endodontics/glide-path/kaur-2024-eal-vs-radiograph-working-length-sr-ma]] 등 근관 길이 측정·글라이드 패스 관련 문헌과 연계.

## Three-line Summary

- 인공 치아(Dentalike)의 제2 근심협측 근관을 대상으로 PathFile, One G, ProGlider 세 종류의 글라이드 패스용 NiTi 파일의 삭제량(중량 감소)과 WaveOne 파일로 본성형 시 최대 토크·총 스트레스를 비교함.
- ProGlider군이 타 기구군 대비 유의하게 많은 삭제량(중량 감소)을 보였으나(p<0.05), 본성형 시 최대 토크와 총 스트레스는 글라이드 패스 유무와 기구 종류 간 유의한 차이가 없었음.
- 글라이드 패스 형성 기구의 기하학적 설계에 따라 삭제 효율 차이가 있으나, 인공 치아 근관 크기의 편차(micro-CT 확인)와 측정 해상도 한계로 결과 해석에 주의가 필요함.

## 세줄요약

- 인공 치아(Dentalike) 제2 근심협측 근관에서 PathFile, One G, ProGlider 세 NiTi 글라이드 패스 파일의 삭제 효율과 후속 WaveOne 성형 시 토크를 비교한 in-vitro 예비 연구임.
- ProGlider가 가장 많은 삭제량(중량 감소)을 보였으나(p<0.05), 본성형 단계 최대 토크·총 스트레스는 군간 유의차 없음.
- 인공 치아 근관 크기 편차와 측정 해상도 한계로 임상적 일반화에 신중을 요함.

## Key Contributions

- 세 종류의 상용 글라이드 패스 NiTi 파일(PathFile, One G, ProGlider) 직접 비교
- 삭제 효율(중량 감소)과 후속 본성형 토크 동시 평가
- Dentalike 인공 치아의 근관 크기 편차(micro-CT 확인) 문제점 지적
- 단일 파일 시스템(ProGlider, One G) vs 다중 파일 시스템(PathFile) 비교 자료 제공

## Methodology

- Study design: In-vitro preliminary study
- Specimen: Dentalike artificial teeth (standardized), mesiobuccal root canal of mandibular molars
- Groups (n not explicitly stated, implied equal allocation):
  1. PathFile group (multiple files)
  2. One G group (single file)
  3. ProGlider group (single file)
  4. No glide path control (direct WaveOne shaping)
- Procedure: Glide path establishment → weigh pre/post (0.1mg resolution) → WaveOne shaping with torque measurement
- Analysis: One-way ANOVA + Tukey post-hoc, α=0.05

## Key Results

- **Weight reduction (cutting efficiency)**: ProGlider > PathFile ≈ One G > Control (ProGlider significantly highest, p<0.05)
- **Maximum torque during WaveOne shaping**: No significant difference among groups
- **Total stress generation during WaveOne shaping**: No significant difference among groups
- **Micro-CT examination**: Dentalike artificial teeth showed discrepancies in root canal size → standardization reliability concern

## Limitations

- 예비 연구(preliminary study)로 표본 크기 작음
- 인공 치아(Dentalike) 사용으로 임상 상황과 차이(치질 경도, 해부학적 변이 부재)
- Dentalike 근관 크기 편차로 표준화 신뢰도 문제 인정
- 단일 파일 시스템(One G, ProGlider)과 다중 파일 시스템(PathFile) 비교이나 파일 수 차이 교란 변수 가능
- 토크 측정만으로 기구 파절 저항성 등 기계적 특성 평가 부족

## Glossary

- **Glide path (글라이드 패스)**: 본성형 전 근관 내 초기 경로를 확보하여 후속 파일 파절 위험을 낮추고 원활한 성형을 돕는 예비 성형 단계
- **NiTi file (니켈-티타늄 파일)**: 초탄성·형상기억 합금으로 만든 근관 성형 기구
- **PathFile**: Dentsply Sirona의 다중 파일 글라이드 패스 시스템(통상 3파일)
- **One G**: Micro-Mega의 단일 파일 글라이드 패스 시스템
- **ProGlider**: Dentsply Sirona의 단일 파일 글라이드 패스 시스템(점진적 테이퍼)
- **WaveOne**: Dentsply Sirona의 단일 파일 왕복 운동 성형 시스템
- **Dentalike**: 표준화된 인공 치아 모형(근관 치료 교육·연구용)
