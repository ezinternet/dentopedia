## Three-line Summary

Technical note (Columbia University, IJOMI 2013) establishing the A/B/C classification of molar extraction sockets for immediate dental implant placement, based on the bone available within the inter-radicular septum (IRS) for primary implant stability: Type A (septum fully engages implant, no gap), Type B (septum partially stabilizes, gaps present), Type C (minimal/absent septum, implant must engage socket periphery).

Each type carries distinct treatment protocols: Type A allows predictable immediate placement with the implant contained within septal bone; Type B requires attention to gap management; Type C represents a high-risk scenario typically requiring delayed placement or prior augmentation.

The classification system was subsequently operationalized with CBCT measurements by Milenkovic 2022, Pavlovic 2022, Deporter 2021, and Ragucci 2020, and has become the standard taxonomic framework for all molar immediate implant literature.

## 세줄요약

기술 보고 (컬럼비아 의대, IJOMI 2013) — 구치 발치와를 격중격(IRS) 내 잔존골에 따라 Type A·B·C로 분류: Type A(격중격이 임플란트를 완전히 감쌈, 틈 없음), Type B(격중격이 부분 고정, 일부 틈 존재), Type C(격중격 거의 없음, 임플란트가 발치와 주변골에 걸쳐야 함).

각 유형별 치료 프로토콜 제시 — Type A는 예측 가능한 즉시식립, Type B는 틈(gap) 관리 필수, Type C는 즉시식립 고위험군(지연식립 또는 골증대 권고).

이후 Milenkovic 2022·Pavlovic 2022·Deporter 2021·Ragucci 2020 등이 CBCT 계측치로 정량화·검증 — 현재 구치 즉시식립 문헌 전반의 표준 분류 기준.

## 2. The A/B/C Classification

Classification criterion: amount and position of inter-radicular septal bone available for implant stabilization.

| Type | Septal Bone | Implant-to-Socket Relationship | Gaps | Clinical Implication |
|---|---|---|---|---|
| **A** | Sufficient to fully engage implant | Implant completely within septal bone | None | Predictable IIP; primary stability from septum alone |
| **B** | Sufficient to stabilize but not surround | Partial septal engagement | Gaps on ≥1 surface | IIP possible; gap management required (graft/membrane) |
| **C** | Little to none | Implant engages socket periphery | Large/circumferential | High-risk IIP; delayed placement or augmentation preferred |

## 3. Clinical Decision Framework

The classification is a pre-surgical decision tool:

1. **Pre-surgical CBCT** → assess IRS height, width, density → assign Type
2. **Type A**: proceed with IIP, implant diameter/design matched to septum
3. **Type B**: plan gap grafting; confirm adequate remaining bone for initial stability
4. **Type C**: consider:
   - Delayed placement after ridge preservation
   - Socket augmentation at extraction → implant at re-entry
   - Septal expansion techniques (e.g., osseodensification — Bleyan 2021)

## 4. Limitations

- Technical note without outcome data — classification not validated against survival rates within this publication
- No CBCT measurement thresholds given — quantification provided by subsequent studies
- Classification is anatomic; does not address socket infection, periapical pathology, or systemic factors
- Molar-specific (mandibular and maxillary), not applicable to single-rooted sockets
