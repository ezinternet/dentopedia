아나필락시스 (Anaphylaxis) 생명위협
치과 유발원: 항생제(아목시실린 ~50%), 클로르헥시딘, 국소마취제, 라텍스 · 영국 입원 ~7/10만/년
인지 증상 (ABCDE 평가)
  • 두드러기·혈관부종 (93% 케이스에서 발생)
  • 기도 부종·천명·호흡곤란 (59%)
  • 저혈압·빈맥 (33%)
  • 갑작스러운 빠른 발현·진행
  • 가려움·피부 홍조
  • 구역·복통
감별: 혈관미주신경성 실신과 비교
  • 아나필락시스: 피부 반응 + 기도·순환 동반
  • 실신: 창백·서맥·땀, 누우면 빠른 회복
  • 아나필락시스: 눕혀도 악화될 수 있음
  • 실신: 발적·두드러기 없음
  • 패닉 어택: 산소포화도 정상 유지
대처 프로토콜 (Resuscitation Council UK 기반)
  1. 아드레날린 즉시 투여 — 지연은 사망 원인 1위 영국 아나필락시스 사망의 ~40%가 아드레날린을 투여받지 못했음
    아드레날린 1:1,000 (1 mg/mL) → 500 µg IM (성인 12세↑)
  2. 투여 부위: 대퇴 전외측 중간 1/3 (vastus lateralis) 삼각근은 흡수 느림 — 비추천. 23G 25mm(파란색) 바늘 사용
  3. 환자 자세 조정 의식 있으면 앉히기(기도부종·호흡곤란 시) / 의식 없으면 바닥에 눕혀 다리 올리기
  4. 119 신고 + 산소 투여 고농도 산소 15 L/min 마스크 투여
  5. 5분 후 미개선 시 아드레날린 반복 반응이 있을 때까지 5분 간격으로 반복 가능
  6. 사후 처리: MHRA Yellow Card 신고 (약물 의심 시) 클로르헥시딘 발치와 세척 → 증례 2건 사망 (영국, MHRA 2014) — 식염수 사용 권고
💉 주사 기법 변경사항: 최신 지침은 IM 대퇴 주사 시 장갑·알코올 소독·바늘-허브 간격·흡인·주사 후 마사지를 모두 생략한다. AAI(에피펜 등)는 다른 아드레날린 제제가 전혀 없을 때만 사용.

BLS + AED 프로토콜 (10항목 기준)
  1. 반응 확인 + 119 신고 어깨를 두드리며 "괜찮으세요?" — 무반응 즉시 119 신고
  2. AED 가져오기 (동시에) 다른 사람에게 "AED 가져와!" 지명 지시 — 즉시 CPR 시작
  3. 가슴압박 시작 — 분당 100~120회, 5~6cm 깊이 손꿈치: 흉골 하부 1/2. 30:2 압박-호흡 비율
  4. AED 전원 ON Phase 1 연구: 4.8%만 성공 → Phase 2(수정 안내): 100% 성공. 음성 안내를 끝까지 따를 것
  5. 배터리 확인 (흔히 빠뜨림) Phase 1에서 0%만 수행 — 정기 점검 필수
  6. 전극 부착: 건조한 맨 가슴 + 올바른 위치 우쇄골하 / 좌액와부 중간. 습기·물기 제거 후 부착
  7. 분석 중 모두 물러나기 (접촉 금지) "물러나세요!" 크게 외치고 직접 확인 후 버튼 누름
  8. 제세동 즉시 실시 목표: 90초 이내. 1분 초과 시 소생률 ~10%/분 감소
  9. 쇼크 직후 즉시 CPR 재개 ⚠️ 가장 놓치기 쉬운 단계 (Phase 1·2 모두 <10% 이행) — 멈추지 말 것
  10. 2분 후 재평가 AED가 안내할 때까지 CPR 중단하지 않음

혈관미주신경성 실신 (Vasovagal Syncope) 긴급
치과 응급상황 중 가장 흔한 유형 · 통증·공포·장시간 술기가 주요 유발
전구 증상 (실신 전)
  • 창백·땀·메스꺼움
  • 어지러움·시야 흐림
  • 서맥 (맥박 느려짐)
  • 하품·허약감
  • 불안·초조
아나필락시스와 감별점
  • 실신: 피부 발적·두드러기 없음
  • 실신: 누우면 수초~분 내 자발 회복
  • 실신: 혈압↓ + 맥박↓ (아나필락시스는 맥박↑)
  • 실신: 기도 부종 없음
  • 실신: 천명음 없음
대처 프로토콜
  1. 치료 즉시 중단 — 자극 제거 버 회전 중지, 손 빼기, 스트레스 요인 즉시 제거
  2. 트렌델렌부르크 자세 (다리 올리기) 체어 눕히고 다리 15~30° 거상 → 뇌 혈류 회복
  3. 기도 유지 확인 입 안 이물질(거즈·기구) 제거. 턱 들어 기도 개방 확인
  4. 산소 투여 (4~6 L/min 비강캐뉼라)
  5. 혈압·맥박 모니터링 3~5분 내 회복 없으면 다른 원인 고려 (아나필락시스, 저혈당, 심정지)
  6. 회복 후 원인 파악 및 예방 공복 방지, 수액 보충, 다음 내원 시 오전 단시간 예약. 소아는 장시간 진료 분할 권고

저혈당 (Hypoglycemia) 긴급
당뇨 환자 치과 내원 중 술중 저혈당 위험 10~15% · HbA1c <9% = 발치 안전 임계값
인지 증상
  • 떨림·발한·창백
  • 혼동·말이 어눌해짐
  • 빈맥·두근거림
  • 허약감·어지러움
  • 두통
  • 심하면: 경련·의식 소실
예방 — 발치 전 확인
  • HbA1c < 9% 확인 후 시술 (안전 임계값)
  • 공복 상태 피하기 — 당일 식사 여부 확인
  • 인슐린 용량 조정 여부 파악
  • 오전 일찍 예약 (혈당이 비교적 안정적)
  • 응급 포도당 준비 (포도당 젤·정맥 포도당)
대처 프로토콜
  1. 술기 즉시 중단
  2. 의식 있는 경우 — 경구 포도당 투여 포도당 정제 15~20g / 오렌지 주스 150 mL / 설탕 물 (설탕 3~4 스푼)
  3. 의식 없는 경우 — 경구 투여 금지 50% 포도당 50 mL 정맥 주사 / 글루카곤 1 mg 근육·피하 주사 → 119
  4. 15분 후 혈당 재확인 혈당 <4 mmol/L(72 mg/dL) 지속 시 재투여
  5. 회복 후 당일 침습 술기 연기

기관지경련 (Bronchospasm / 급성 천식 발작) 긴급
천식/COPD 치과 환자 발생률 3~6% · 치과 스트레스·약물이 주요 유발
인지 증상
  • 천명음 (쌕쌕거림, 날숨 시 더 뚜렷)
  • 호흡 곤란·가슴 답답함
  • 기침·호흡수 증가
  • 산소포화도 하강
  • 보조 호흡근 사용
  • 심하면: 청색증·의식 변화
예방 — 시술 전 확인
  • 천식 조절 상태 확인 (최근 발작 여부)
  • 흡입 기관지확장제 지참 확인
  • 아스피린·NSAID 사용 시 주의 (일부 천식 악화)
  • 아황산염(메타바이설파이트) 포함 국소마취제 피하기
  • 불안 조절 — 산화질소 진정 고려
대처 프로토콜
  1. 술기 중단 + 직립 자세 앉은 자세 또는 약간 앞으로 기울인 자세 — 눕히지 않음
  2. 환자 본인 흡입기 사용 (살부타몰 2~4 puff) 효과 없으면 5분 후 반복. 클리닉 비치 살부타몰 MDI 사용
  3. 산소 투여 (4~6 L/min)
  4. 5~10분 내 미개선 → 119 즉시 신고 중증 천식은 빠르게 악화 가능 — 지연 금지
  5. IV 접근 확보 + 에피네프린 고려 (아나필락시스 동반 시)

고혈압 위기 (Hypertensive Emergency) 주의
고혈압: 성인 최대 30% 유병률 · 술중 혈압 상승 위험 20~25% · BP ≥180/110 = 발치 연기 기준
인지 증상
  • BP ≥ 180/110 mmHg (측정값)
  • 심한 두통·후두부 통증
  • 시야 흐림·눈 통증
  • 코피
  • 어지러움·불안
  • 심하면: 가슴 통증·호흡 곤란 (장기 손상 징후)
예방 — 시술 전 혈압 측정
  • BP < 180/110 mmHg → 발치 진행 가능
  • BP ≥ 180/110 mmHg → 발치 연기 + 내과 의뢰
  • 에피네프린 2~3 카트리지 이하 사용
  • 심혈관 고위험: 에피네프린 1:200,000 이하 농도
  • 통증·불안 조절로 혈압 급등 예방
대처 프로토콜
  1. 술기 중단 + 자극 최소화 통증 유발 중단, 조용하고 안정된 환경 제공
  2. 반좌위 자세 + 혈압 재측정 5~10분 안정 후 재측정
  3. 기저 항고혈압제 복용 확인 오늘 약 복용 여부 — 미복용 시 복용 권장
  4. BP ≥ 180/120 + 증상 → 119 신고 뇌졸중·심근경색 징후(가슴통증·편마비·언어장애) → 즉각 119
  5. 내과 의뢰 후 재예약 혈압 조절 확인 후 재내원 계획 수립
