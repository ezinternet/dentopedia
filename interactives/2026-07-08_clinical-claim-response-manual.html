열린치과 · claim-coach 연계 · 내부 참조용

임상 클레임 대응 매뉴얼 — A·F·E

통증·기능(A) · 심미(F) · 협박·과도요구(E) — 상황별 3톤 스크립트, 체어사이드 즉시 검색·복사

근거: 민원 과학 21편(wiki/complaint-management/) + 통합 오버뷰. 분류·기대진단(Friele)·status theory·법적 가드는 claim-coach 스킬 규칙을 그대로 반영. 모든 스크립트는 초안이며 실제 사실관계·클리닉 톤에 맞춰 조정할 것 — 최종 책임은 작성자.

사용 전 공통 체크 — 신경손상·감염확산·의료사고 정황, 손해배상/고소/언론제보 언급, 비합리적 반복 금전요구가 보이면 이 매뉴얼의 표준 스크립트 대신 원장 직접 응대 + 기록 즉시 보전으로 전환. E(협박·과도요구) 카드는 이미 이 전제로 작성됨.
A 임플란트 식립 후 지속 통증 임상+관계
[기대진단] 재발 방지·정직한 설명 > 사과 — 이 통증이 정상 범위인지 문제인지 알고 싶어함.
공감우선식립 후에도 계속 불편하시면 많이 걱정되실 것 같아요. 어떤 식으로 아프신지 여쭤보고, 원장님께 바로 확인해서 살펴보겠습니다.
균형식립 초기에는 어느 정도 불편감이 있을 수 있지만, 계속되신다면 정확한 확인이 우선입니다. 원장님과 함께 상태를 점검하겠습니다.
전문성말씀 확인했습니다. 정확한 원인은 직접 진찰해야 판단 가능해, 원장님 진료로 점검 후 필요한 조치를 안내드리겠습니다. 예약 잡아드릴까요?
가드 — "골융합 실패" 등 원인 단정 금지, 어떤 톤에서도.
A 크라운·브릿지 저작 시 불편 (교합 이상) 임상
[기대진단] 원인 설명 + 빠른 조정.
공감우선씹을 때마다 불편하시면 일상이 힘드셨겠어요. 교합 상태를 바로 확인해서 조정해 드리겠습니다.
균형교합이 맞지 않으면 저작 시 불편할 수 있습니다. 지금 상태를 확인해서 조정 방향을 안내드리겠습니다.
전문성교합 확인이 필요한 상태로 보입니다. 진료 후 조정 여부와 범위를 말씀드리겠습니다.
가드 — 조정 시행 자체를 "잘못 만들어서" 같은 과실 인정 문구로 번역하지 않는다.
A 신경치료(근관치료) 후 통증 지속 임상+관계 ⚠️
[기대진단] 재발 방지 우선 — 근관치료는 의료과실 청구 노출 최대 영역(Alrahabi 2019).
공감우선치료 후에도 계속 아프시면 걱정되고 속상하실 것 같아요. 어떤 식으로 아프신지 여쭤보고 원장님께 바로 확인하겠습니다.
균형치료 후 회복 과정에서 일시적 통증이 남는 경우도 있지만, 정확한 상태 확인이 먼저입니다. 원장님과 함께 살펴보겠습니다.
전문성통증 원인은 여러 가지일 수 있어 직접 확인이 필요합니다. 진료로 상태 점검 후 추가 처치 여부를 안내드리겠습니다.
가드 — 기구파절·누락 근관 등 원인 단정 금지. 기록·러버댐 사용 여부 사전 확인 권고(Alrahabi 2019).
A 보철물 반복 탈락·파절 임상+관리
[기대진단] 재발 방지(구조적 원인 확인).
공감우선또 빠지셨다니 번거로우셨겠어요. 원인을 확인해서 같은 일이 반복되지 않게 살펴보겠습니다.
균형반복해서 빠지는 경우 원인 확인이 중요합니다. 교합이나 접착 상태를 점검하고 조치하겠습니다.
전문성반복 탈락은 원인 파악이 우선입니다. 확인 후 필요하면 접착 방식이나 구조를 조정하는 방향을 안내드리겠습니다.
가드 — 재제작·무상 처리는 "검토 후 안내"가 상한. 호의성 무상 재치료는 이후 배상액 산정에 영향 미칠 수 있어(Kwon 2017) 서면 합의의 영역이다.
A 발치 후 통증·부종 지속 임상
[기대진단] 감염 여부 확인 안심 + 즉시 조치.
공감우선발치 후에도 계속 붓고 아프시면 많이 불안하셨겠어요. 지금 바로 상태를 확인해 보겠습니다.
균형발치 후 일정 기간 붓기·통증은 있을 수 있지만, 지속되면 확인이 필요합니다. 진료로 상태를 점검하겠습니다.
전문성지속되는 통증·부종은 감염 등 원인 확인이 필요합니다. 바로 진료 보시고 필요한 처치를 안내드리겠습니다.
가드 — 감염 관련은 즉시 배양·치료·적시 의뢰·기록이 판례상 책임 분기점(Park 2016). 응대 문구보다 내원 유도가 우선.
A 미백 후 시린 증상 임상
[기대진단] 일시적 증상인지 확인 + 관리법 안내.
공감우선미백 후 시린 느낌이 있으면 불편하셨겠어요. 어느 정도인지 여쭤보고 확인해 드리겠습니다.
균형미백 후 일시적으로 시릴 수 있는데, 어느 정도 지속되시는지 확인해서 관리법을 안내드리겠습니다.
전문성시림 정도·기간 확인이 필요합니다. 진료로 상태를 보고 필요하면 관리 방법을 안내드리겠습니다.
가드 — "원래 그런 겁니다" 류 훈계 금지. 흔한 증상이어도 환자에게 그렇게 말하지 않는다.
A 틀니 압박통·궤양 임상+관계
[기대진단] 빠른 조정 + 정직한 설명 — 고령 환자 배려 우선.
공감우선그 자리 계속 아프고 헐었으면 식사도 힘드셨겠어요. 바로 확인해서 조정해 드리겠습니다.
균형압박되는 부분이 있으면 궤양이 생길 수 있습니다. 확인해서 조정하겠습니다.
전문성압박 부위 확인이 필요합니다. 진료로 점검 후 조정하겠습니다.
가드 — 절차보다 안심 문구를 앞에 두는 것이 관계 domain 우선 원칙에 부합.
F 크라운·보철물 색상 불만족 관계 우세
[기대진단] 확인 후 조정 가능 범위 안내 — 환불·재제작 약속 아님.
공감우선생각하신 색과 달라서 아쉬우셨겠어요. 직접 보여주시면 어느 부분이 다른지 정확히 확인해 보겠습니다.
균형색감은 주관적으로 느껴지실 수 있어, 직접 비교해서 조정 가능한 범위를 확인해 보겠습니다.
전문성색상 차이는 확인이 필요합니다. 진료 시 직접 비교하고, 조정 가능 범위를 안내드리겠습니다.
가드 — "재제작해 드리겠습니다" 무상 약속 금지 — "조정 가능 범위는 확인 후 안내"까지만.
F 라미네이트·베니어 형태/두께 불만 관계+임상
[기대진단] 확인 후 조정 가능 여부 안내.
공감우선생각하신 모양과 달라 불편하셨겠어요. 어떤 부분이 어색하게 느껴지시는지 직접 보여주시면 확인하겠습니다.
균형형태에 대한 느낌은 사람마다 다를 수 있어, 실제로 어떤 부분이 다른지 확인 후 조정 여부를 말씀드리겠습니다.
전문성형태 확인이 필요합니다. 진료 시 직접 비교해 조정 가능한 범위를 안내드리겠습니다.
가드 — 서면 동의서 존재 여부가 소송 결과를 가름(Grillo 2023) — 시술 전 동의서·기대치 합의 기록을 내부적으로 확인.
F 잇몸 라인·비대칭 불만 관계
[기대진단] 치유 경과 설명 + 확인.
공감우선신경 쓰이셨겠어요. 어느 부분이 비대칭으로 느껴지시는지 직접 확인해 보겠습니다.
균형잇몸 라인은 치유 경과에 따라 달라질 수 있어, 현재 상태를 확인하고 필요한 조치를 안내드리겠습니다.
전문성확인이 필요한 부분입니다. 진료로 상태를 점검하고 조정 가능 여부를 말씀드리겠습니다.
가드 — 반복적·과도한 불만족이 지속되면 신체이형장애(BDD) 가능성 참고(Nabavizadeh 2023) — 임상 판단은 원장 몫, 환자에게 직접 언급하지 않는다.
F 검치(gummy smile) 교정 후 불만족 관계+임상
[기대진단] 정직한 설명 + 재평가 경로.
공감우선기대하신 것과 달라 아쉬우셨겠어요. 어느 부분이 다르게 느껴지시는지 직접 보여주시면 확인하겠습니다.
균형심미적 변화는 사람마다 기대치가 다를 수 있어, 현재 상태를 확인하고 추가로 가능한 부분을 안내드리겠습니다.
전문성확인이 필요한 부분입니다. 원장님 진료로 점검 후 추가 조정 가능 여부를 말씀드리겠습니다.
가드 — 심미 치료는 서면 동의서 유무가 소송 결과를 가름(Grillo 2023) — 시술 전 기대치 합의 기록 확인.
F 틀니 심미(입술 지지·앞니 배열) 불만 관계
[기대진단] 조정 가능 범위 설명.
공감우선생각하신 모습과 달라 속상하셨겠어요. 어떤 부분이 어색하게 느껴지시는지 여쭤보고 확인하겠습니다.
균형배열이나 지지감은 시착 단계에서 조정 가능한 경우가 많습니다. 확인 후 안내드리겠습니다.
전문성확인이 필요한 부분입니다. 진료로 점검 후 조정 가능 범위를 안내드리겠습니다.
가드 — 무상 재제작 약속 금지 — "조정 가능 범위 확인 후 안내"가 상한.
E 임플란트 실패 + 전액환불·피해보상 요구 + 신고·폭로 협박 임상+관리 ⚠️ 신중초안
[레드플래그] 단독 응대 종료 → 원장 보고, 가급적 2인 응대, 대화 내용 즉시 기록(녹취 가능 전제). 3톤 변주 대신 신중 초안.
대면(현장)불편을 겪으신 점 말씀해 주셔서 감사합니다. 원인은 직접 확인해야 정확히 판단할 수 있어, 원장님 진료로 상태부터 살펴보겠습니다. 환불·보상 부분은 제가 이 자리에서 결정할 사안이 아니라 확인 후 정식으로 안내드리겠습니다.
서면(후속)말씀하신 내용 잘 접수했습니다. 상태는 내원해서 확인하는 것이 우선이며, 확인 후 절차에 따라 검토 결과를 안내드리겠습니다.
가드 — 협박 문구("신고하겠다" 등)는 인용·반박하지 않고 "확인 → 절차 → 정식 안내"로 전량 흡수. 금액·환불 가부 언급 제로.
E 근관치료 실패 + 손해배상 요구 임상 ⚠️ 신중초안
[레드플래그] 근관치료는 판례상 책임 분기점이 기록·처치 적절성(Alrahabi 2019) — 임상 조치가 응대 문구보다 우선.
대면많이 놀라고 속상하셨겠습니다. 정확한 상태는 원장님이 직접 확인해야 판단할 수 있어, 진료부터 진행하겠습니다. 배상 관련 부분은 확인 후 별도로 안내드리겠습니다.
서면말씀하신 내용 확인했습니다. 진료 기록 확인 후 관련 절차에 따라 안내드리겠습니다. 내원 가능하신 일정을 알려주시겠어요?
가드 — 원인·과실 단정 금지. 배상 논의는 확인 후 정식 절차로만.
E 발치 후 신경손상 의심 + 손해배상 요구 + 협박 임상 ⚠️ 신중초안
[레드플래그] 신경손상 정황은 원장 직접 대응 + 진료기록 즉시 보전 필수.
대면많이 걱정되고 불안하셨겠습니다. 신경 관련 증상은 정확한 진단이 필요해, 원장님이 직접 확인 후 필요하면 큰 병원 의뢰까지 안내드리겠습니다. 배상 부분은 이 자리에서 결정할 사안이 아니라 확인 후 정식으로 안내드리겠습니다.
서면말씀하신 증상 확인했습니다. 신경 손상 여부는 정확한 검사가 필요해 내원을 권해드리며, 확인 후 절차에 따라 안내드리겠습니다.
가드 — 의학적 확정("신경이 손상됐습니다") 금지 — "정확한 상태는 확인 후"로만.

공통 금지 표현 (모든 카드에 적용)

  • 과실 인정 금지 — "저희 실수입니다", "처치가 잘못됐네요"
  • 원인 단정 금지 — "~때문에 그렇습니다" → "확인이 필요합니다"
  • 배상·금액 약속 금지 — "환불해 드리겠습니다" → "검토 후 안내드리겠습니다"
  • 의학적 확정 금지 — "신경이 손상됐습니다" 단정 → "정확한 상태는 확인 후"
