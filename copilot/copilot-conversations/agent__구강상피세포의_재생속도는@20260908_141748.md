## 기저층 → 표면까지의 구강상피 재생 사이클 (확장 설명)

### 1. 구강상피의 구조

구강 점막은 **편평상피 (stratified squamous epithelium)**로, 아래에서 위로 층이 구분됩니다:

| 층 | 역할 | 세포 상태 |
|---|---|---|
| **기저층 (Stratum basale)** | 줄기세포·증식 | 단층 원기둥세포, 핵 존재, 활발한 유사분열 |
| **돌기층 (Stratum spinosum)** | 파라기저세포 → 중간분화 | 다층, 세포 간 다리(데스모좀) 발달 |
| **입자층 (Stratum granulosum)** | 말단 분화 시작 | 각질과립(keratohyalin granule) 축적, 세포 평탄화 |
| **표면층 (Superficial/keratinized)** | 탈락 | 편평세포, 무핵, 각질막, 타액으로 방출 |

### 2. 사이클의 단계별 메커니즘

**① 기저층 증식 (Proliferation)**
- 기저층의 줄기세포가 끊임없이 유사분열합니다.
- 세포 주기 시간이 매우 짧아, 2.7시간 내에 한 번의 표면층 교체가 완료됩니다 [Dawes 2003].
- 이 증식은 **두 가지 경로로 조절**됩니다:
  - **증식(Proliferation)**: PI3-K / p38-MAPK / MEK 경로 [Ohshima 2002]
  - **이동(Migration)**: MEK / TK(tyrosine kinase) / PI3-K 경로 (증식과 별개의 신호체계) [Ohshima 2002]

**② 위쪽으로 이동 (Migration)**
- 기저층에서 분열한 딸세포는 위로 밀려 올라갑니다.
- 구강 각질세포는 피부 각질세포보다 **약 12% 더 빠르게 이동**합니다 (1.73 μm/min vs 1.55 μm/min) [Drukala 2005].
- 이동 경로는 더 **직선적**입니다(CDE 0.55 vs 0.36).
- 구강점막 각질세포의 빠른 이동은 **골수유래세포(bone marrow-derived cell)**의 높은 모집과도 관련됩니다 [Glim 2013].

**③ 열감응성 활성화 (TRPV3)**
- 구강 상피에서는 피부보다 **TRPV3 채널 발현이 더 높습니다** [Aijima 2014].
- 구강 체온(~33°C 이상)에서 TRPV3가 활성화 → Ca²⁺ 유입 → **EGFR(EGFR/ErbB) 인산화** → 증식 촉진.
- 이것이 구강 상피가 체온 환경에서도 높은 증식율을 유지하는 열(thermal) 기전입니다.

**④ 각질화 (Keratinization)**
- 세포가 입자층에 도달하면:
  - 핵과 세포소기관이 소실
  - 케라틴 중간섬유와 케라토히알린 입자가 축적
  - 세포막이 각질막(cornified cell envelope)으로 강화
- 이 과정에서 세포는 더 얇고 평평해집니다.

**⑤ 탈락 (Shedding / Desquamation)**
- 표면층의 각질세포가 최종적으로 타액과 함께 빠져나옵니다.
- Dawes (2003)는 타액에 떠나오는 상피세포를 **Coulter Counter로 직접 계측**하여 이 탈락률을 정량화했습니다.
- 결과: 표면층 전체가 **2.7시간마다** 완전히 교체.

### 3. 2.7시간이라는 숫자의 의미

Dawes의 계산 방법:

```
표면층 교체 시간 = (구강 점막 면적 / 개별 세포 면적) × 타액 중 세포 농도 × 삼키는 비율
```

- **무치악(무 tooth) 구강** 기준
- **항정상태(Steady-state)** 가정: 세포 생산량 = 세포 탈락량
- 이 값은 피부 표피(14–28일)보다 약 **500배 이상 빠릅니다**.

### 4. 왜 이렇게 빠른가? — 적응적 의미

| 요인 | 설명 | 근거 |
|---|---|---|
| **마찰·손상 방어** | 음식물·치아·세균과의 물리적 접촉이 잦아 세포 교체가 빈번해야 함 | Glim 2013 |
| **빠른 창상 치유** | 구강 상처는 피부보다 재상피화가 빠르고 흉터가 적음 | Glim 2013 |
| **세균 도메인 유지** | 약 15.8억 개의 세균이 구강 점막 위에 거주 → 세포 교체가 세균 생태계와 밀접 | Dawes 2003 |
| **TRPV3 기전** | 체온(33°C+)에서 지속적 활성화 → 높은 기저 증식율 | Aijima 2014 |
| **타액 EGF** | 생리 농도 1–10 ng/mL의 EGF가 항상 증식+이동 촉진 | Ohshima 2002 |

### 5. 한계

- Dawes 2003은 **무치악 구강**만 연구; 치아·치은열구(sulcus)는 포함되지 않음 → 실제 치아 보유 구강에서는 더 복잡
- **항정상태 가정**: 염증·건조증(xerostomia)·질환 시에는 이 속도가 변할 수 있음
- Ohshima 2002은 **암종 유래 세포주(HO-1-N-1)** 사용 → 정상 점막과의 차이 가능성
