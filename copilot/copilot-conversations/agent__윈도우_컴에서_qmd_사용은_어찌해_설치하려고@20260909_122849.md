**ai**: `qmd`는 로컬 하이브리드 검색 도구(BM25 + vector + LLM re-rank)입니다. Windows에서 설치는 다음과 같이 진행합니다.

먼저 레포의 설정 지침을 확인해 보이전 세션에서 비슷한 질이 있었군요. `setup-qmd.sh`는 macOS 전용이지만, Windows에서도 `qmd`를 사용할 수 있습니다. 핵심 차이점은 **Homebrew가 없으니 Node.js와 SQLite를 별도 설치**해야 한다는 것입니다.

---

## Windows에서 qmd 설치 방법

### 1단계: 사전 요구사항 설치

**Node.js 22+** (필수):
- [nodejs.org](https://nodejs.org) 에서 **LTS 22.x** 다운로드 후 설치
- 또는 `nvm-windows` 사용:
  ```powershell
  nvm install 22
  nvm use 22
  ```

**SQLite (FTS5 지원)**:
- `qmd`는 SQLite의 FTS5(Full-Text Search) 확장이 필요합니다
- 두 가지 방법 중 하나:
  - **방법 A**: [sqlite.org](https://www.sqlite.org/download.html) 에서 `sqlite-tools-win32-*.zip` 다운로드 → `sqlite3.exe`를 PATH에 추가
  - **방법 B**: `npm install -g better-sqlite3` (내장 SQLite 포함, FTS5 기본 활성화)

```powershell
# SQLite 확인
sqlite3 :memory: "CREATE VIRTUAL TABLE fts ON fts USING fts5(content);"
```
FTS5 명령어가 에러 없이 실행되면 준비 완료.

---

### 2단계: QMD 전역 설치

```powershell
npm install -g @tobilu/qmd
```

설치된 경로가 `PATH`에 추가되었는지 확인하세요. `npm`의 global 경로가 보통 `%APPDATA%\npm`인데, 이게 PATH에 없을 수 있습니다:

```powershell
# PATH에 npm global 폴더 추가 (영구)
[Environment]::SetEnvironmentVariable("Path", $env:Path + ";$env:APPDATA\npm", "User")
```

---

### 3단계: 임베딩 모델 저장 경로 설정 (PowerShell)

macOS의 `~/.zshrc` 대신, PowerShell 프로필에 환경변수를 박습니다:

```powershell
# PowerShell 프로필 열기 (없으면 생성)
notepad $PROFILE
```

아래를 추가:

```powershell
$env:QMD_EMBED_MODEL = "hf:Qwen/Qwen3-Embedding-0.6B-GGUF/Qwen3-Embedding-0.6B-Q8_0.gguf"
```

또는 세션마다 환경변수로도 가능:

```powershell
$env:QMD_EMBED_MODEL = "hf:Qwen/Qwen3-Embedding-0.6B-GGUF/Qwen3-Embedding-0.6B-Q8_0.gguf"
```

### 4단계: 컬렉션 등록

```powershell
cd C:\Users\oracleneo\llm-wiki

qmd collection add "sources" --name sources --mask "**/*.md"
qmd collection add "agenda" --name agenda --mask "**/*.md"
qmd collection add "note-meeting" --name meetings --mask "**/*.md"
```

### 5단계: 컨텍스트 부여

```powershell
qmd context add qmd://wiki "치과학 위키 페이지(영어). 논문 1편=1페이지, frontmatter + [[wikilinks]]."
qmd context add qmd://sources "논문 PDF의 LLM 요약(영어)."
qmd context add qmd://agenda "작업 명세서."
qmd context add qmd://meetings "미팅 기록."
```

### 6단계: 임베딩 생성

```powershell
qmd embed
```

- 첫 실행 시 GGUF 모델이 다운로드됩니다 (수 분 소요)
- Windows에서는 `%USERPROFILE%\.cache\qmd\` 에 캐싱됩니다

---

### 7단계: MCP HTTP 데몬 기동

```powershell
qmd mcp --http --daemon
```

Claude Code에 HTTP MCP 등록:

```powershell
claude mcp add --transport http qmd http://localhost:8181/mcp
```

`claude` 명령어가 없으면 직접 `~/.claude/settings.json`에 추가:

```json
{
  "mcpServers": {
    "qmd": { "type": "http", "url": "http://localhost:8181/mcp" }
  }
}
```

### Windows 특이사항 & 팁

| 항목 | macOS | Windows |
|------|-------|---------|
| 셸 스크립트 | `.sh` (bash) | `.ps1` (PowerShell) 또는 `.cmd` |
| 홈 디렉토리 | `~` | `$env:USERPROFILE` |
| npm global 경로 | `/usr/local/bin` | `%APPDATA%\npm` |
| SQLite 설치 | `brew install sqlite` | 직접 다운로드 또는 `better-sqlite3` |
| 환경변수 파일 | `~/.zshrc` | `$PROFILE` (PowerShell) |
| MCP 데몬 | `launchd` | `qmd mcp --http --daemon` (터미널에서 실행) |
| 백그라운드 드레인 | `launchctl` | `bash scripts/embed-until-done.sh` (PowerShell 백그라운드) |

**주의사항**:
- `qmd embed`는 백그라운드에서 돌려도 Windows PowerShell 세션이 닫히면 프로세스가 종료됩니다. 장시간 임베딩이 필요한 경우 `Start-Process -NoNewWindow`로 백그라운드 실행하거나, CMD `.cmd` 래퍼를 사용하세요
- `qmd mcp --daemon`도 같은 문제 — 별도 터미널 창에서 돌리거나 Windows 서비스로 등록해야 합니다
- `qmd cleanup`은 고아 벡터 제거용 — Windows에서도 동일하게 동작합니다

**정리**: Windows에서는 `setup-qmd.sh`를 그대로 쓸 수 없으니, 위 단계를 PowerShell로 수동 진행하면 됩니다. 핵심은 **Node.js 22+ + SQLite(FTS5) + `npm install -g @tobilu/qmd`**입니다.

혹시 `qmd` 실행 시 에러가 나오면 어떤 메시지인지 알려주세요 — PATH 문제든 SQLite FTS5 문제든 잡아드리겠습니다. `[미검증]` — 실제 Windows 환경에서 돌려보지 않아 확인은 안 됨.
