위키 `immediate-implant/` 90여 편 + overview 2편에서 종합합니다. 먼저 중요한 구분: **IIP의 생존율은 95–98%로 모든 타이밍(Type 1–4)에서 동등**하므로 [확인], 임상에서 실제 "실패"는 두 가지 다른 얼굴로 온다 — **생물학적 실패**(골유착 실패·조기 실패)와 **심미 실패**(점막 퇴축·PES 실패). 대부분의 위험인자는 후자에 집중되어 있다.

## 1. 심미 실패 — IIP의 핵심 위험 (3대 위험인자)

Chen 2009 ITI consensus (91편) 기준 3대 위험인자, **누적될수록 Type 2(4–8주 지연)로 전환**한다 [확인 — [[overviews/immediate-implant-conditions]]]:

| 위험인자 | 근거 수치 |
|---|---|
| **얇은 협측벽 ≤1 mm** | 수직 골소실 중앙값 **7.5 mm vs 두꺼운 벽 1.1 mm** (Chappuis 2013); 상악 전치부의 **90%가 <1 mm** (Chappuis 2017) — 가장 강력한 단일 위험인자 |
| **임플란트 협측·근심 위치** | 협측 숄더 위치 시 설측 대비 **3배 퇴축** (1.8 vs 0.6 mm, Evans 2008) |
| **얇은 생체형 (thin biotype)** | 점막 퇴축 위험 증대 |

이 3가지가 겹치면 Type 1 심미 실패 위험은 **20–30% 점막 퇴축**까지 (Buser 2017 ITI) [확인]. 즉, "심미부 무작정 즉시식립"이 가장 흔한 실패 경로다.

## 2. 부위·해부학적 요인 (CBCT 생략 시 실패)

- **상악동 병변**: Aung 2024 (49개, 7.4년 후향) — 부위별 5년 생존: 하악·소구치 **100%**, 상악 대구치 95.8%, **상악 전치부 85.4% 최저**, 실패 3건 전부 상악동 병변(부비동염·기낭화·기왕 수술) 연관 [확인]. → 상악동 병변 socket은 지연식립+거상 우선.
- **1차 안정성 불가**: IT <25 Ncm 예상이면 Type 2로 전환 [확인]. 단, 예외적으로 IT<10 Ncm·ISQ<55였던 16개 무피판 SLA가 ISQ 42.2→68.7 상승 후 65개월 생존 100% (Jang 2025) — **절대값보다 ISQ 상승 궤적**이 신호 [확인].
- **하악 구치부**: 하치조관(IAC) 근접 — 제2대구치 치근첨~관 거리 평균 **4.65 mm**로 최단, 언더컷형 능선(73%)에서 설측 피질 천공 위험 (Behfarnia 2025) → ≥2 mm 안전 마진 + CBCT 필수 [확인].
- **상악 소구치 천공**: 보철주도 축 **84.1%**, 최적 골주도 축조차 **40.5%** 천공 — 전치부 ~5.6% 대비 현저히 높음 (Najm 2024 CBCT) [확인].
- **절개관·비강 근접** (Panda 2018), **협측벽 결손**: ≥2–5 mm면 Type 3+GBR, ≥5 mm면 Type 4 (단 Meijer 2024 10년 RCT는 숙련 GBR 시 동등) [확인].
- **감염 socket**: 만성 치근단 병변은 소파+항생제 동반 시 가능하나, **급성 화농성 농양은 조기식립(8–12주), 활동성 화농·봉와직염은 절대 금기** [확인].

## 3. 환자·전신 요인

- **흡연·당뇨 미조절**: 당뇨 IIP는 생존율은 건강군과 대등하지만 **불량 혈당조절 시 MBL·BOP 유의 증가** (양호조절 대비 약 5배 차이, Li 2026 SR+MA) [확인].
- **술후 항생제**: Lang 2012 (46편, 2년 생존 98.4%)에서 검토한 5개 후보 요인 중 **항생제 사용만이 실패 위험을 유의하게 감소**시킴 [확인].

## 4. 술식 요인 (실패를 부르는 조작 오류)

- **Jumping gap ≥2 mm 미충전** → 협측 흡수 증가 (−0.84 vs −0.46 mm, Sanz 2017 RCT) [확인]
- **구개측 식립 <2 mm** → 협측 치조정 보존 실패 (Staas 2026) [확인]
- **가이드 수술의 IIP 특유 실패 모드**: 가이드는 발치 전 try-in 불가 → 적합성 술전 검증 불가, 협측·설측 골 저항 차로 드릴이 순측 편향 (Xing 2024) [확인]
- **소켓실드(SST) 합병증 9.5–17%** (실드 노출·이동), 무합병증 생존 90.5% — 표준 프로토콜(gap 충전+임시치관+CTG)이 더 안전 [확인]
- **즉시부하 기준 미달 무시**: 발치와 ISQ는 인공적으로 낮음(57.6 vs 치유골 72.9) → **IT ≥35 Ncm이 1차 기준**, 즉시부하는 IT≥35 + ISQ≥70 양조건 [확인 — [[overviews/isq-loading-threshold]]]

## 5. 타이밍 자체의 실패 부담 (생존은 동등, 방향성 신호)

- Felice 2016/Esposito 2017 (n=210 3-arm RCT): 실패율 즉시 6.0% / 6주 6.2% / 지연 1.6% — **유의하지 않지만 지속적 우위가 없는 방향** [확인]
- Tonetti 2017 (n=124 RCT): 의도한 즉시식립의 **7.5%가 불가능**했고, 골증대 필요 72% vs 44%, 창상 치유 실패 26% vs 5%, 부적절 PES 42% vs 19% [확인]
- Fan 2024 SR+MA (11 RCT, n=701): IIP가 MBL 보존엔 우위(비구치 −0.36 mm)지만 **술후 합병증은 유의하게 더 많음** [확인]

결론부터: **30 Ncm 토크의 대부분은 마찰로 사라지고, 실제 축방향 조임력(프리로드, Preload)으로 남는 것은 일부뿐**입니다. 위키의 어버트먼트 스크류 종합 페이지 [[overviews/abutment-screw-preload-joint-stability-overview]] (20편 종합) 근거로 정리합니다.

## 1. 토크의 분해 — 어디로 가는가

| 성분 | 비율 | 출처 |
|---|---|---|
| **나사 머리(헤드 시트) 마찰** | ~**50%** | Sagheb 2023 실측 [확인] |
| 나사산 마찰 등 | ~40% | 상동 [확인] |
| **프리로드(축방향 압착력)로 전환** | **~8–10%** | Lee 2025 [확인] |

"8–10%"라는 숫자는 에너지 관점의 변환 효율 비유이고, 실제로 임상적으로 의미 있는 값은 **결과물인 힘(N)**입니다. 실측 데이터: DLC(탄소) 코팅 나사를 **25 Ncm로 조였을 때 프리로드 329.9 N** (첫 조임 기준, Sagheb 2023) [확인]. 같은 실험에서 이 나사를 10회 재사용하면 마찰계수가 0.33→0.44로 오르며 프리로드가 329.9→253.7 N으로 떨어졌습니다 [확인].

→ 25 Ncm에서 ~330 N이었으므로, **30 Ncm에서는 나사·표면 조건이 같다면 대략 350–400 N 수준**으로 추정됩니다 (비례 추정이라 [미검증] — 다만 "치과 임플란트 나사 30 Ncm ≈ 300–400 N 클램핑력"은 문헌 상식 범위와 일치).

## 2. 그 힘은 무엇을 하는가

프리로드는 지대주(어버트먼트)를 임플란트에 **압착하는 클램핑력(clamping force)**입니다. 나사 풀림이 발생하는 순간은 **관절 분리력(joint-separating force: 저작력 + 캔틸레버 + 넓은 교합면)이 잔존 클램핑력을 넘어서는 때**입니다 (Krishnan 2013) [확인]. 나사의 항복강도 대비 최적 프리로드는 **항복강도의 ~75% (파절강도의 65%)** 수준이 설계 기준 [확인].

## 3. 조임 직후부터 부하는 계속 줄어든다

걸어둔 "부하"는 정적이지 않습니다. 두 가지 손실 경로:

- **세틀링 (settling/embedment)**: 무하중에서도 접촉면 미세조도 붕괴로 조임 직후 수분 내 **2–10% 프리로드 손실** (Pardal-Peláez 2017; 일부 연구 2–15%) [확인]
- **동적 피로**: 저작 하중 반복으로 최종 **제거토크 손실 16.1–39%** — 특히 삽입 후 5만–100만 사이클 구간에 집중 (Selvi 2025) [확인]

즉 30 Ncm로 조였어도 1년 뒤 실질적으로는 "20 Ncm 상당" 이하로 내려가 있을 수 있다는 뜻입니다.

## 4. 그래서 임상 프로토콜은 (동일 페이지의 8단계 중 핵심)

- **보정된 토크렌치 사용**: 기계식 토크렌치는 설정값보다 **11–29.3% 낮게 전달** (Marenzi 2026) → 30 Ncm 설정이 실제로는 21–27 Ncm일 수 있음 [확인]
- **지정 토크 준수, 과토크 금지**: ~35 Ncm가 가장 안정적 프리로드, 40 Ncm는 보호 효과 없음 (Lee 2025); 항복 초과 시 프리로드 손실·나사 파절 (Vélez 2020) [확인]
- **초기 체결 후 단시간 내 재토크**: 세틀링 보상 — 고전 10분 vs 2분 (Varvara 2020이 2분이 최소 손실) [확인], 재토크는 2회째에서 plateau (Saleh-Saber 2017) [확인]
- **재사용 금지**: 코팅 나사 재사용 시 마찰 상승으로 프리로드 저하 (Sagheb 2023) [확인]
- **연결부 청결**: 내부 육각 오염만으로도 초기 프리로드 유의 감소 (Sun 2026) [확인]

참고: 나사 설계 자체도 프리로드 유지를 좌우합니다 — 오스템 KSIII(수정형)는 전 토크 범위에서 토크 손실 <25%인 반면 TSIII(기존형)는 36.5–51.8% 손실 (~2.5–3.0배) [확인]. 실무에서 "30 Ncm로 조이면 된다"는 **지정값 전달이 보장되는 절차**(보정 렌치 + 재토크 + 청결) 없이는 보장되지 않습니다.
