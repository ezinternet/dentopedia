## ISQ 활용방법 — 위키 기반 합성

**핵심 원칙**: ISQ는 단독 결정 지표가 아니라 **5요소(ISQ + 삽입토크 + 골질 + 표면처리 + 시점) 종합 판단**의 일부입니다.

### 1. 부하 결정 임계값

| ISQ | 권고 |
|---|---|
| **≥70** | 표준 부하 안전선 (Andersson 2019, n=745, 5년 누적생존율 97.3%) |
| **65–69** | 조기부하 후보, 삽입토크 보조 필수 |
| **60–64** | 지연부하 + 모니터링 |
| **<60** | 4–6개월 지연 또는 재평가 |

### 2. 시나리오별 적용

- **즉시부하**: ISQ ≥70 **+** 삽입토크 ≥35 Ncm 양조건 충족 (Wittneben 2023 SR)
- **6–8주 조기부하**: 삽입토크 >40 Ncm 단독으로도 가능 (Andreatta 2020)
- **D4 골 (상악 구치부)**: ISQ 58–65이 정상 분포 — 70 미달이라고 자동 지연 결정 아님 (Rosa 2024)
- **신선 발치와**: ISQ 인위적으로 낮음 (~57 vs 치유골 ~72) → 삽입토크를 1차 기준으로

### 3. 안정성 딥 (Stability Dip) 활용

식립 후 2–4주에 1차(기계적) 안정성→2차(생물학적) 안정성 전환 시 ISQ 하락 발생. **부하 결정은 식립시 단일값보다 2–4주 후속 측정이 더 신뢰성 높음.**

### 4. 측정 실무

- SmartPeg 한 번 체결, 협설 측정 한 번이면 충분 (Osstell ICC=0.97)
- 4방향 평균 의무 아님
- Anycheck(IST)는 Osstell과 동등한 경향, 측정자 독립적

### 5. ISQ 단독 사용 금지 이유

- ISQ–삽입토크 상관 r=0.44 (중등도, 비교 불가)
- ISQ는 치조정 3mm 이내 피질골만 반영 (해면골·심부 무관)
- 표면처리에 따라 안정성 딥 양상 다름

## ISQ 측정 변동 — 정상 범위 vs 오류

### 정상 변동 범위

- **<3 ISQ 변동**: Parmar 2024 (n=60)에서 SmartPeg I는 46.3%, SmartPeg II는 58.6%의 케이스에서 3 미만 변동 → **3–5 ISQ 정도 변하는 건 흔함**
- **조임 토크 영향 무시 가능**: Kastel 2019 (체외)에서 수동 조임(2–11 Ncm) vs 기계 조임(2–6 Ncm) 간 ISQ 차이 없음 (p=0.343 근심, p=0.890 협측)
- **측정 방향 무시 가능**: Herrero-Climent 2013에서 협설 vs 근원심 방향차 임상적 유의 없음

### 변동이 크다면(10 이상) 확인할 점

| 확인 항목 | 근거 |
|---|---|
| **SmartPeg 체결 상태** — 헐거거나 불완전 체결 | 수동 조임은 임상적으로 충분하나(Kastel 2019), 완전히 체결되지 않으면 공진주파수 왜곡 |
| **SmartPeg 손상** — 나사산 마모/변형 | Won 2008: 400회 탈착에서도 ISQ 73.2–74.1 범위 유지, but 나사산 훼손 시 영향 |
| **임플란트 상부 구조물 연결 상태** | abutment 연결 후 측정 불가 (Meredith 1996, Herrero-Climent 2013) |
| **측정 위치 일관성** —每次都 다른 방향 | SmartPeg I vs II는 동등(Herrero-Climent 2013), but 혼용 시 변동 가능 |
| **골밀도 비균일** — 측정마다 다른 골 접촉 | Chatvaratthana 2017: 치조정 피질골 두께가 ISQ 지배적 결정인자(r=0.885) |

- **한 번 체결 후 협측 1회 측정이면 충분** — 4방향 평균 불필요 (Herrero-Climent 2013, ICC=0.97)
- **변동이 5 이상이면**: SmartPeg 재체결 후 재측정
- **변동이 10 이상이면**: SmartPeg 교체 또는 임플란트 상부 구조물 점검

결과적으로:
- p=0.343 (근심), p=0.890 (협측) → 둘 다 0.05보다 큼
- 따라서 귀무가설을 **기각할 수 없음**

### 1. 가설검정의 구조

### 2. p값의 의미

**p값**: 귀무가설이 **참이라고 가정**했을 때, 현재 관찰된 결과(또는 더 극단적인 결과)가 나올 **확률**

- p = 0.03 → 귀무가설이 참이라면, 이런 결과가 나올 확률이 3%
- p = 0.50 → 귀무가설이 참이라면, 이런 결과가 나올 확률이 50%

### 3. p값 해석의 핵심

| p값 | 판단 | 의미 |
|---|---|---|
| **p < 0.05** | 귀무가설 **기각** | "차이가 없다"는 주장이 **틀렸다**고 판단 |
| **p ≥ 0.05** | 귀무가설 **기각 불가** | "차이가 없다"는 주장이 **틀리지 않았다**고 판단 |

| 오해 | 올바른 이해 |
|---|---|
| ~~p < 0.05 → 효과가 크다~~ | p < 0.05는 효과의 **크기**가 아니라 **유의성**만 나타냄 |

         ↓
3. 결과를 본다 (누가 더 빨랐나?)
         ↓

         ↓

| 의미 | 예시 |
