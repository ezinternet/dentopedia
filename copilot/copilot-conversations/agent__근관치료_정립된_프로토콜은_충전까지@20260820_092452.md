### ④ 세정·소독 (Irrigation & Activation) — 핵심 병목

| 항목 | 근거 | 출처 |
|---|---|---|
| **CNI(일반 주사기) 단독 금지** — 모든 단계에서 활성화 기법 필수 | sr+ma (umbrella) | [[overviews/irrigation-activation-comparison]], Orozco-Gallego 2025, Tonini 2022 |
| **PUI(수동초음파세정) 1순위** — 미생물 감소(RD −0.15), 치유(RD −0.09) 최강 근거 | sr+ma (4 SR+9 MA) | [[overviews/irrigation-activation-comparison]], Orozco-Gallego 2025 |
| 근첨 도달 우선 → **ANP(EndoVac)** 최선 (PUI보다 도달 우수, 단 임상 치유 격차 미확정) | sr+ma | [[overviews/irrigation-activation-comparison]], Kumar 2023 |
| **세정액 화학 분업**: NaOCl(유기질 용해) + 킬레이트제(무기질 제거) 병용 필수. NaOCl 단독은 도말층 무기질 제거 불가 | sr | [[overviews/irrigation-activation-comparison]], Fortea 2024, Mohammadi 2019 |
| **증류수 중간세정 필수** — NaOCl + EDTA/CHX/QMix 직접 접촉 시 PCA(파라클로로아닐린) 침전 | narrative | [[overviews/irrigation-activation-comparison]], Shalavi 2021 |
| 킬레이트제 선택: **17% EDTA(표준)** / HEDP(NaOCl 양립) / 7% 말레산(근첨 도말층 우위, 1–3분 한정) | sr | [[overviews/irrigation-activation-comparison]], Fortea 2024, Rao 2025 |
| 레이저(Er:YAG PIPS/SWEEPS)는 대리지표 일관 우위, NaOCl 농도↓, 술후 불편↓ — 단 **outcome-level RCT 부재** | sr (15편 전원 동방향) | [[overviews/irrigation-activation-comparison]], Fiegler-Rudol 2025 |
| 내원간 약제는 **선택적** — 농양·대형병소·재치료에 한정. CH(1차 표준, ~99.5% 미생물 감소) / TAP(E. faecalis 표적) | sr+ma | [[overviews/irrigation-activation-comparison]], Ardila 2026, Shunmugavelu 2025 |
| **단회치료로 충분** — 다회 Ca(OH)₂ 대비 성공률 동등~단회 우위. 의자시간 ~31분 단축 | rct + sr+ma | [[overviews/irrigation-activation-comparison]], Wong 2015, Rossi-Fedele 2023 |

**세정 10단계 실무 프로토콜**:
```
1. NaOCl 1–6% + PUI 활성화 (1–3분) → 유기질 용해 + 항균
2. 증류수 중간 flush → PCA 침전 방지
3. 킬레이트제 (EDTA 17% 또는 HEDP) + PUI (1분) → 도말층 제거
4. 증류수 final flush
5. (옵션) QMix 또는 CHX 최종 세척 → 잔류 항균 (NaOCl 직접 혼합 금지)
```

**WL + 충전 종지점 통합 정리**:

| 술전 진단 | 목표 WL | 근거 |
|---|---|---|
| 생활치수 / 근단 병소 없음 | AC에서 다소 물러남 (RA −1mm 부근 무방), 과기구조작 회피 | Chugal 2003, Schaeffer 2005 |

│  3. Glide path → Rotary/Reciprocating NiTi 형성           │

│     → 진단별 조절: 생활치수 약간 물러남 / 괴사+AP 근첨 근접   │

## ⚠️ 회색지대 · 반대근거

- **단회 vs 다회**: 단회 ≥ 다회이지만, 농양·대형병소·증상 지속 시 내원간 CH 드레싱은 여전히 선택적 (Rossi-Fedele 2023)
- **어떤 활성화법·신규 세정제도 outcome-level 이득 미입증** (Gupta 2025, Boutsioukis 2022) — 대리지표에서만 우위
- **충전 기법 장기 차이 소멸** (Mushtaq 2026) — 24개월 CLC·CB 소폭 우위 이후 3년 이후 수렴
- **최종 보철 적합도** — Ng(유의) vs Ricucci(무영향) 엇갈림, 숙련도·baseline confounder

한 줄 요약: **TEC 접근 → 보존적 형성 → EAL 진단종속 WL → NaOCl+EDTA+PUI 세정 → 진단 기준 WL 충전(urgent: 근첨 근접, vital: 약간 물러남) → 밀폐 보철**이 위키 근거 기반 정립된 전체 프로토콜이다.

| 지속 살균·항염 (표준) | **CH** (~99.5%, 저렴) | Shunmugavelu 2025 |
| E. faecalis 의심 (재치료·난치) | CH 단독 금물 → **TAP/CHX/RG-Dent** | Ardila 2026, Hasan 2026, Asnaashari 2022 |
| 급성 통증 | **Ledermix** (최속) → TAPC/나노 | Shunmugavelu 2025 |
| VPT (DPC/pulpotomy) | **Biodentine/MTA** — CH는 대안 | Hatipoglu 2025 |
| CH 제거 시 | PUI 활성화 (NaOCl+EDTA 병용 시 차이 소실) | Zhou 2021 SR+MA |

⚠️ **회색지대**
- Bedran 2020의 LPS 감소는 GRADE **very low** — pre-post 설계·이질성 높음
- CH의 치유 이득 미입증은 "효과 없다"가 아니라 **"다회 내원의 루틴 정당화가 약하다"** — 지속 삼출(weeping canal)·급성 농양에서는 여전히 내원간 항균 통제 수단 [확인]

한 줄 요약: **CH는 근관 소독의 표준 첩약이지만, E. faecalis 성숙 바이오필름엔 열세, 통증엔 약하고, 루틴 첩약의 치유 이득은 없으며, VPT에선 1차가 아니다 — 목적에 맞게 선택하되 2일 적용으로 충분하다.**

*의사결정 지원용 — 최종 임상 판단·책임은 술자에게 있습니다.*
