이 위키의 `.md` 파일들을 **하이브리드 검색**(BM25 + vector + LLM re-rank)해주는 로컬 도구입니다. `localhost:8181`에서 MCP 서버로 돌아가야 하고, 별도 데몬이 필요합니다.

### QMD 없이도 검색은 됩니다

내가 가진 도구들:

| 도구 | 용도 | 예시 |
|---|---|---|
| `grep` | 파일 내용 검색 (정규식 지원) |某个 단어가 들어간 wiki 페이지 찾기 |
| `glob` | 파일명 패턴 검색 | `wiki/**/*.md` 같은 패턴 |
| `read` | 파일 직접 읽기 | 특정 wiki 페이지 열기 |
| `qmd query`/`qmd search` | QMD 하이브리드 검색 | 개념·저자명·수치 등 |

QMD가 죽어있으면 `grep`/`glob`로 fallback합니다 — CLAUDE.md에도 그렇게 적혀있어요.

### 내부 검색 vs 웹 검색

- **내부 검색**: `grep`, `glob`, `read`, `qmd` → 이 위키 안에서만
- **웹 검색**: `WebSearch`, `WebFetch` → 외부 사이트 (단, Rule #1상 **질문에 답할 때는 절대 웹 검색 안 함**)

### 1. CLI로 직접 사용

